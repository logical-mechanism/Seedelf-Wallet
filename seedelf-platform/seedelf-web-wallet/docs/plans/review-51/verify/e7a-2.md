## Trace: partly, low

Half of it holds, and that half is the narrower one. While Stop's cost read is still running (`cost === undefined`), the dialog shows the direct way's words. Those are "…less the return's network fee.", or "The cancel and the return each cost a network fee." once an order is out. It shows no Lovejoin switch, and its "Stop the swap" button is enabled. Pressing it sends `session-stop` without `direct`, so `auto.direct` stays false and the swap comes back through Lovejoin, as approved. The failing test shows this.

The headline trigger is refuted: a failed read (Koios's 429, the data layer down) never becomes `null`. Every network read under `stopCost` is caught where it's made:
- `rooms()` uses try/catch and returns undefined.
- `readSet` falls back to the set it last handed over.
- `lookSoon` and `facts` are both `.catch`ed.

With no room read, `priced` counts every box the ADA pays for (`fitsOf` gives Infinity). The passing test shows this: with all three Koios requests answered 429, `stopCost` still resolves with 2 boxes, 1.9 ₳ of mix fees and 0.6 ₳ to bring them back. A 429 only stretches the window while the read runs: the client retries after 1 s and 3 s, and a 429 holds every request for 10 to 60 s.

The page's `() => setStopCost(null)` branch is reached only by:
- a trap, which locks the wallet;
- a locked store;
- a session already over, where openStop's fresh read closes the dialog and `automatic` refuses Stop;
- a worker that dies mid-request.

None of these leaves a live Stop that goes through Lovejoin under the direct words. The last is the only exception, and it is negligible.

Grade: low. Who: the user, pressing Stop inside the read window. That window is near-instant within 5 minutes of a Review's pool read, otherwise a few seconds, and longer under a 429. The cost is the approved Lovejoin way's fees and delay instead of one network fee: in the run, 2.5 ₳ and 6 to 24 h a box for a 16 ₳ funding, more boxes for a bigger swap. The approval's ifStopped line disclosed that cost, and the dialog itself shows "Working out what goes through Lovejoin…". The way out is to wait for the read, after which the switch appears. There is no way back after the press.

// Chunk 51, finding e7a#2 (the trace verifier): Stop's dialog on a swap approved to come back through Lovejoin.
//
// The finding has two halves. The first, a cost read that fails (Koios's 429, the data layer down) taken for "comes
// back directly", doesn't happen: every pool read under stopCost is swallowed where it's made (lovejoin.ts rooms(),
// readSet(), adaPool's lookSoon, collateralPoolTakes' facts), and a pool with no room read counts every box the ADA
// pays for (priced's fitsOf). The first test pins that, and passes on the tree. The second half holds: while the read
// is under way (`cost === undefined`, which a 429's retries and hold stretch), the dialog says the direct way's cost,
// shows no switch, and its Stop button sends no `direct`, so the swap comes back as approved, through Lovejoin. The
// second test fails on the tree.
import { Children, createElement, type ReactElement, type ReactNode } from "react";
import { renderToStaticMarkup } from "react-dom/server";
import { describe, expect, it } from "vitest";

import { NetworkContext } from "../src/ui/network";
import { StopDialog } from "../src/ui/screens/Swaps";
import { lovejoinOf } from "./chain-fixtures";
import { ASK, atSession, signing, unlocked } from "./swap-session";

/** Ogmios's answer when the network measures no more than a transaction declares. */
const AGREES = { jsonrpc: "2.0", method: "evaluateTransaction", result: [] };

/** A page's text, as a person reads it (swap-page.test.ts). */
function text(element: ReactElement): string {
  return renderToStaticMarkup(createElement(NetworkContext.Provider, { value: "preprod" }, element))
    .replace(/<[^>]+>/g, " ")
    .replaceAll("&#x27;", "'")
    .replaceAll("&quot;", '"')
    .replaceAll("&amp;", "&")
    .replace(/\s+/g, " ")
    .trim();
}

type Props = Parameters<typeof StopDialog>[0];

/**
 * Stop's dialog as it reads, and what its Stop button (the last in its foot) sends when pressed: `direct`, or
 * nothing where it can't be pressed.
 */
function opened(props: Pick<Props, "placed" | "pools" | "cost" | "through">): { words: string; sent?: boolean } {
  let sent: boolean | undefined;
  let modal: ReactElement | undefined;
  const all: Props = {
    ...props,
    busy: false,
    onThrough: () => undefined,
    onClose: () => undefined,
    onStop: (direct) => {
      sent = direct;
    },
  };
  // The dialog's own element, its hooks run inside this render.
  function Probe() {
    modal = StopDialog(all) as ReactElement;
    return modal;
  }
  const words = text(createElement(Probe));
  const foot = (modal!.props as { foot: ReactElement }).foot;
  const buttons = Children.toArray((foot.props as { children: ReactNode }).children) as ReactElement[];
  const stop = buttons.at(-1)!.props as { disabled?: boolean; onClick: () => void };
  if (!stop.disabled) stop.onClick();
  return { words, sent };
}

describe("Stop on a swap approved to come back through Lovejoin (chunk 51, e7a#2)", () => {
  it("prices its return through Lovejoin even when every pool read fails: a 429 is no 'directly'", { timeout: 60_000 }, async () => {
    const t = await unlocked();
    t.koios.evaluation = AGREES;
    const now = t.clock.now;
    const out = "ab".repeat(32);
    await t.store.set("sessions.preprod", {
      next: 1,
      sessions: [
        {
          index: 0,
          ownStake: true,
          createdAt: now,
          txs: [{ kind: "out", txHash: out, at: now, confirmed: true }],
          swap: { ...ASK, amountOut: "906594100", minAmountOut: "902083681" },
          auto: {
            approved: { minAmountOut: "902083681", fund: { lovelace: "16000000", tokens: [] } },
            direct: false,
            lovejoin: { depth: 1, delay: "6-24", box: "5000000" },
          },
        },
      ],
    });
    t.koios.addedToAccounts.push(atSession("c1".repeat(32), 0, "40000000"), atSession(out, 1, "5000000"));
    // Discovery hands over the 5 ₳ pool (lovejoinOf), and Koios then answers every request 429.
    const sessions = signing(t, { lovejoin: lovejoinOf(t), sleep: async () => undefined });
    let asked = 0;
    t.koios.fetch = async () => {
      asked++;
      return new Response("Too Many Requests", { status: 429 });
    };
    const cost = await sessions.stopCost("preprod", 0);
    // It asked, was refused, and still answers with the boxes: the dialog shows the switch, never null's words.
    expect(asked).toBeGreaterThan(0);
    expect(cost).not.toBeNull();
    expect(cost!.skipped).toBeUndefined();
    expect(cost!.boxes).toBeGreaterThan(0);
  });

  it("never says the direct way's cost while its cost is read, where its Stop then brings it back as approved", () => {
    // What the direct way alone costs, as the dialog words it.
    const directOnly = ["less the return's network fee", "The cancel and the return each cost a network fee"];
    const seen: string[] = [];
    for (const placed of [false, true]) {
      for (const pools of [false, true]) {
        // As openStop leaves it: the read under way, the switch on as approved.
        const { words, sent } = opened({ placed, pools, cost: undefined, through: true });
        // Pressed now, Stop sends no `direct`: the swap comes back as approved (sessions.ts stop, throughLovejoin),
        // through Lovejoin for this one. Only a press that brings it back directly may say the direct way's cost.
        if (sent !== false) continue;
        for (const phrase of directOnly) if (words.includes(phrase)) seen.push(`placed ${placed}, pools ${pools}: "${phrase}" in "${words}"`);
      }
    }
    expect(seen).toEqual([]);
  });
});
