**Fix notes:**

**Minimal fix:** re-randomize the given register before minting, at seedelf-cli/src/commands/util/mint.rs:83: `new_register.rerandomize()?`. `rerandomize` re-checks that both points are on the curve and torsion-free. An identity point stays the identity, which core's `is_payable` in `mint_from` still refuses. The result stays the recipient's, since the same d is applied to both points, so the recipient's `is_owned` scan finds it as before. Checked in a copy: the test above passes with exactly this change.

**Fixing the class:** the duty sits in core's contract ("used as given: pass a fresh re-randomization", build.rs:3031-3032, and the same shape in `account_mint` at :3876-3900). Core's `mint_from` and `account_mint` could re-randomize the register they're given, so no future caller can write one verbatim. A second re-randomization by callers that already do one is harmless. The doc comment would change with it.

**The family, checked:** this branch is the only caller that writes a given register. create.rs:94, mint.rs:72, fund.rs:161, core's transfer, and the WASM's `mint_spend` (lib.rs:2404) and `account_mint_plan` (lib.rs:2811) all re-randomize.

//! Chunk 51, finding r4#8: `util mint -g -p` writes the register it's given
//! as the new Seedelf's datum unchanged (`commands/util/mint.rs:76-83`, then
//! `seedelf-core`'s `mint_from`, whose `set_inline_datum(seedelf.to_vec())`
//! uses it as given). The README's `util mint` row has the minter use the
//! recipient's `util base` register, `(G1, G1^x)`, so two people minting a
//! Seedelf for the same recipient put one datum on chain twice, and anyone
//! scanning the contract sees both Seedelfs are one person's. `create` and
//! `util mint` without the flags write a fresh re-randomization each time.
//!
//! The right behaviour: a Seedelf minted for someone else sits under a fresh
//! re-randomization of the register given, still theirs (one scalar on both
//! points), so no two mints share a datum and none is the base register.
//!
//! Drives the real `util mint` run twice, with two different minters, against
//! the CLI's offline mock Koios, reusing `tests/cli/harness.rs` as is.

#[path = "cli/harness.rs"]
mod harness;

use blstrs::Scalar;
use serial_test::serial;

use seedelf_cli::commands::util::mint::{MintArgs, run};
use seedelf_core::build::is_payable;
use seedelf_crypto::register::Register;
use seedelf_crypto::schnorr::random_scalar;

use harness::*;

/// A fresh minter (each `Scenario` has its own wallet scalar) mints a Seedelf
/// for the holder of `recipient`, given as `-g` and `-p`, from one owned UTxO
/// `n`. Returns the minted Seedelf's datum, after checking the transaction
/// conserves value, keeps every output above its minimum, and gives the
/// change back to the minter. The scenario drops here, before the next starts.
async fn mint_for(recipient: &Register, label: &str, n: u64) -> Register {
    let mut scenario = Scenario::start().await;
    scenario
        .mount_credential_utxos(vec![wallet_utxo(scenario.scalar, n, 10_000_000, &[])])
        .await;
    scenario.mount_evaluate_mint(1).await;
    scenario.mount_collateral().await;
    scenario.mount_submit().await;

    run(
        MintArgs {
            label: Some(label.to_string()),
            generator: Some(recipient.generator.clone()),
            public_value: Some(recipient.public_value.clone()),
            utxos: None,
        },
        PREPROD,
        VARIANT,
    )
    .await
    .expect("util mint -g -p should succeed");

    let params = protocol_params().await;
    let tx = decode_tx(&scenario.submitted_cbor().await);
    assert_value_conserved(&tx, &scenario.ledger);
    assert_no_sub_min_outputs(&tx, &params);

    let policy = seedelf_policy();
    let minted: i128 = tx
        .mint
        .iter()
        .filter(|((p, _), _)| p == &policy)
        .map(|(_, qty)| *qty)
        .sum();
    assert_eq!(minted, 1, "exactly one Seedelf token is minted");

    let wallet = wallet_address();
    let (seedelfs, change): (Vec<&DecodedOutput>, Vec<&DecodedOutput>) = tx
        .outputs_to(&wallet)
        .into_iter()
        .partition(|o| o.assets.keys().any(|(p, _)| p == &policy));
    assert_eq!(seedelfs.len(), 1, "one output holds the new Seedelf");
    assert_eq!(change.len(), 1, "one change output");
    let back = change[0].register.as_ref().expect("the change carries a Register");
    assert!(
        back.is_owned(scenario.scalar).expect("change ownership"),
        "the change goes back to the minter"
    );
    seedelfs[0]
        .register
        .clone()
        .expect("the Seedelf output carries a Register datum")
}

#[tokio::test]
#[serial]
async fn util_mint_for_someone_else_rerandomizes_the_register_given() {
    // Alice's key, and what `util base` prints for her: `Register::create`.
    let alice: Scalar = random_scalar();
    let base = Register::create(alice).expect("Alice's base register");
    let g1 = Register::create(Scalar::from(1u64))
        .expect("G1")
        .generator;
    assert_eq!(base.generator, g1, "util base's generator is G1 itself");

    // Bob mints her a Seedelf from the register she gave him, then Carol does.
    let from_bob = mint_for(&base, "for alice", 1).await;
    let from_carol = mint_for(&base, "for alice too", 2).await;

    // Holds today and after a fix: each is Alice's, and safe to pay.
    for (minter, datum) in [("Bob", &from_bob), ("Carol", &from_carol)] {
        assert!(
            datum.is_owned(alice).expect("ownership"),
            "{minter}'s mint must sit under a register Alice's key owns"
        );
        assert!(is_payable(datum), "{minter}'s mint must sit under a payable register");
    }

    // The bug: each Seedelf's datum is Alice's base register, byte for byte.
    assert_ne!(
        from_bob, base,
        "Bob's mint put Alice's base register on chain as given, not re-randomized"
    );
    assert_ne!(
        from_carol, base,
        "Carol's mint put Alice's base register on chain as given, not re-randomized"
    );
    assert_ne!(
        from_bob.generator, g1,
        "a Seedelf minted for someone else is marked by G1 as its generator"
    );
    assert_ne!(
        from_bob, from_carol,
        "two Seedelfs minted for Alice share one datum: anyone can see they're one person's"
    );
}
