# e2b#2: verification

## Trace: confirmed, low

The finding holds as described, and two runs on TREE show it. When a second return goes before a swap session closes, it overwrites both fields the finished swap page reads.
- `received` is overwritten by every return (sessions.ts:5522, in sendRecorded's first update, before the submit).
- `lovejoinSkipped` is overwritten by every direct return (sessions.ts:5078, in sendBack's `after`).

A stranger paying the one-time account in that window is enough. The address is on chain since the funding. The close (sessions.ts:3794) waits until nothing returnable is listed, the runner reads every 15 s, and a wallet locked after the return was sent leaves the session open until the next unlock.

Results:
- **Direct return:** the closed page says "Received 1.829439 ₳". The swap's own return brought back 906.5941 MIN and 133.411421 ₳.
- **Return through Lovejoin:** the swap's own return was a real chain (deposit, mix, back), which finished and was not cut. The closed page still says "Directly: Lovejoin was left out" and "Lovejoin was left out of its return: its spare ADA is too little for a box…", and "Received, besides its boxes in Lovejoin 1.829439 ₳".

The balance and each return's private history are right. With a two-line fix sketch applied in a copy, the same test passes.

Corrections and narrowings to the finder:
- **Paths:** a filled order swap reaches its second return through :3868 then :3904. A swap whose return went through Lovejoin goes through :3816. Only a swap stopped before its order goes through :3836.
- **Dust doesn't trigger it:** a stranger's payment too small to come back is left behind (TOO_LITTLE) before anything is sent, so for a swap neither field is written. This differs from e2b#1's `mix.skipped`, which is written before the build. The stranger has to pay roughly 1.6 ₳ or more, and the user keeps it.
- **A fourth way, with no stranger:** the C03 path that swap-runner.test.ts:444 builds ("brings back what's left of the session's own once the fill is recorded and a return is in") makes a second return of the session's own change.
- **Not run:** the other two ways (a missed funding part landing after Stop's return, and an order copy Koios took).

Severity is low:
- **Who:** a stranger, who must pay real ADA to the user inside the window, or a rare glitch path with the session's own money.
- **Cost:** no money. A closed page's after-the-fact summary understates what the swap got by its whole proceeds, and wrongly says Lovejoin was left out, which errs on the pessimistic side.
- **Way out:** the balance and Activity show the truth.
- **Why not medium:** it is literally "a figure off by real money", but nothing is decided or signed on that figure.

// Chunk 51, e2b#2: a finished swap's page says what its return brought back (`received`, chunk 23's second review,
// DX-5) and how it came back (`lovejoinSkipped`: the timeline's last step and the skip callout). A later return of the
// same session, of what a stranger paid its account before it closed, writes both over: sendRecorded replaces
// `received` with each return's own figures, and sendBack writes that return's own skip reason. The closed swap then
// says it received only the stranger's ADA, never its 906.5941 MIN, and that Lovejoin was left out of its return,
// though its own return went through Lovejoin. The real WebAssembly, Lovejoin v2's 5 ₳ pool (v2-pools.ts), and fakes
// of Koios, giveme.my and Minswap, as sessions.test.ts's "places the order once the funding lands, …" and
// swap-lovejoin-way.test.ts run them.
import { createElement } from "react";
import { renderToStaticMarkup } from "react-dom/server";
import { describe, expect, it } from "vitest";

import { DEFAULT_PREFERENCES } from "../src/shared/preferences";
import type { SessionView } from "../src/shared/rpc";
import { NetworkContext } from "../src/ui/network";
import { PreferencesContext } from "../src/ui/preferences";
import { Session } from "../src/ui/screens/Swaps";
import { lovejoinOf } from "./chain-fixtures";
import { ASK, atSession, funded, fundingOutsSpent, MIN, ordered, orderRow, signing, started, SWAP_TX, unlocked, type T } from "./swap-session";
import { ADA_ROWS } from "./v2-pools";

/** Ogmios's answer when the network measures no more than a transaction declares. */
const AGREES = { jsonrpc: "2.0", method: "evaluateTransaction", result: [] };

/** Real chains are built and measured in WebAssembly: seconds each. */
const CHAINS = { timeout: 180_000 };

/** A stranger's payment to session 0's account, made after its own return went. */
const STRANGER = "c9".repeat(32);

/** The swap's proceeds, as a return's figures name them. */
const PROCEEDS = expect.objectContaining({ assetName: MIN.slice(56), quantity: "906594100" });

type Recorded = {
  txs: Array<{ kind: string; txHash: string; confirmed?: boolean }>;
  received?: { lovelace: string; tokens: Array<{ assetName: string; quantity: string }> };
  lovejoinSkipped?: string;
  closedAt?: number;
};

/** Session 0's sealed record, as the runner left it. */
async function record(t: T): Promise<Recorded> {
  return (await t.store.get<{ sessions: Recorded[] }>("sessions.preprod"))!.sessions[0]!;
}

/** The session's page, as a person reads it, balances shown (swap-page.test.ts's `shown`). */
function page(s: SessionView): string {
  return renderToStaticMarkup(
    createElement(
      PreferencesContext.Provider,
      { value: { prefs: DEFAULT_PREFERENCES, loaded: true, set: async () => undefined } },
      createElement(
        NetworkContext.Provider,
        { value: "preprod" },
        createElement(Session, { session: s, reading: false, onRefresh: () => undefined, onBack: () => undefined, onChanged: () => undefined }),
      ),
    ),
  )
    .replace(/<[^>]+>/g, " ")
    .replaceAll("&#x27;", "'")
    .replace(/\s+/g, " ")
    .trim();
}

describe("a finished swap whose account a stranger paid before it closed (chunk 51, e2b#2)", () => {
  it("still says it received what its own return brought back, once the stranger's 2 ₳ came back too", async () => {
    const t = await unlocked();
    const sessions = signing(t);
    await started(sessions);
    funded(t);
    fundingOutsSpent(t);
    // The funding landed: the runner places the order.
    let view = await sessions.advance("preprod", 0, true);
    expect(view.txs.map((x) => x.kind)).toEqual(["out", "swap"]);

    // The order lands and a batcher fills it: everything at the account comes back in one return.
    ordered(t);
    t.koios.spent.add(`${SWAP_TX}#0`);
    t.koios.addedToAccounts.push(atSession("aa".repeat(32), 0, "2000000", [[MIN, "906594100"]]));
    view = await sessions.advance("preprod", 0, true);
    expect(view.txs.map((x) => x.kind)).toEqual(["out", "swap", "back"]);
    expect(t.koios.submitted).toHaveLength(3);
    const own = (await record(t)).received!;
    expect(own.tokens).toContainEqual(PROCEEDS);

    // That return lands. Before the runner's next look would close the session, someone pays its account 2 ₳: its
    // address is on chain since the funding. The runner brings that back too, in a return of its own.
    t.koios.spent.add(`${SWAP_TX}#1`).add(`${"aa".repeat(32)}#0`);
    t.koios.addedToAccounts.push(atSession(STRANGER, 0, "2000000"));
    view = await sessions.advance("preprod", 0, true);
    expect(view.txs.map((x) => x.kind)).toEqual(["out", "swap", "back", "back"]);
    expect(t.koios.submitted).toHaveLength(4);

    // It lands, and the session is over.
    t.koios.spent.add(`${STRANGER}#0`);
    view = await sessions.advance("preprod", 0, true);
    expect(view.stage).toBe("closed");
    // What the swap got: its own return's 906.5941 MIN and ADA, not the stranger's 2 ₳ less a fee alone.
    expect(view.received?.tokens).toContainEqual(PROCEEDS);
    expect(BigInt(view.received?.lovelace ?? "0")).toBeGreaterThanOrEqual(BigInt(own.lovelace));
    expect(page(view)).toMatch(/Received 906\.5941 MIN/);
  });

  it(
    "never says Lovejoin was left out of its return, which went through Lovejoin, for the stranger's 2 ₳ that came back directly",
    CHAINS,
    async () => {
      const t = await unlocked();
      t.koios.evaluation = AGREES;
      t.koios.confirmations = 1;
      const now = t.clock.now;
      const out = "ab".repeat(32);
      const fill = "aa".repeat(32);
      const done = (kind: string, txHash: string, extra = {}) => ({ kind, txHash, at: now, confirmed: true, ...extra });
      // A swap approved to come back through Lovejoin, one wave deep, its order placed and on chain.
      await t.store.set("sessions.preprod", {
        next: 1,
        sessions: [
          {
            index: 0,
            ownStake: true,
            createdAt: now,
            txs: [done("out", out), done("swap", SWAP_TX, { orders: [`${SWAP_TX}#0`] })],
            swap: { ...ASK, amountOut: "906594100", minAmountOut: "902083681" },
            auto: {
              approved: { minAmountOut: "902083681", fund: { lovelace: "16000000", tokens: [] } },
              direct: false,
              lovejoin: { depth: 1, delay: "1-6", box: "5000000" },
            },
          },
        ],
      });
      // Filled: the order is spent, and the account holds the proceeds, the swap's change and its 5 ₳ collateral.
      t.koios.addedToAccounts.push(
        orderRow(SWAP_TX, 0),
        atSession(fill, 0, "2000000", [[MIN, "906594100"]]),
        atSession(SWAP_TX, 1, "12000000"),
        atSession(out, 1, "5000000"),
        ...ADA_ROWS,
      );
      t.koios.spent.add(`${SWAP_TX}#0`);
      // Its collateral's own mix into the 5 ₳ pool is off: the return asked about here is its chain alone.
      await t.deps.preferences.set({ lovejoinCollateral: false });
      const sessions = signing(t, { lovejoin: lovejoinOf(t), sleep: async () => undefined });

      // The runner sees the fill and brings it all back through Lovejoin, as approved: one chain, the return last.
      await sessions.advance("preprod", 0, true);
      let kept = await record(t);
      const kinds = kept.txs.map((x) => x.kind);
      expect(kinds.slice(0, 3)).toEqual(["out", "swap", "deposit"]);
      expect(kinds.at(-1)).toBe("back");
      expect(kept.lovejoinSkipped).toBeUndefined();
      const own = kept.received!;
      expect(own.tokens).toContainEqual(PROCEEDS);

      // All of it is on chain. Before the runner's next look would close the session, a stranger pays its account
      // 2 ₳, too little for a box: it comes back directly, in a return of its own.
      t.koios.spent.add(`${fill}#0`).add(`${SWAP_TX}#1`).add(`${out}#1`);
      t.koios.addedToAccounts.push(atSession(STRANGER, 0, "2000000"));
      await sessions.advance("preprod", 0, true);
      kept = await record(t);
      expect(kept.txs.filter((x) => x.kind === "back")).toHaveLength(2);

      // It lands, and the session is over.
      t.koios.spent.add(`${STRANGER}#0`);
      const view = await sessions.advance("preprod", 0, true);
      expect(view.stage).toBe("closed");
      // Its chain went in and finished: the page's last step would read "Through Lovejoin".
      expect(view.chain).toMatchObject({ cut: false });
      expect(view.chain?.stopped).toBeUndefined();
      // The swap's own return went through Lovejoin: its page never says Lovejoin was left out of it, nor that it
      // received the stranger's ADA alone.
      expect(view.lovejoinSkipped).toBeUndefined();
      const words = page(view);
      expect(words).not.toContain("Lovejoin was left out");
      expect(view.received?.tokens).toContainEqual(PROCEEDS);
      expect(words).toMatch(/Received, besides its boxes in Lovejoin 906\.5941 MIN/);
    },
  );
});
