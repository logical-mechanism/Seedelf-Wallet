# r4#7: verification

From lane R4, graded low by its finder.

## Trace: confirmed, low

Confirmed by a run. `util extract` compares the whole address of the UTxO it is asked to rescue with the contract's enterprise form, so it refuses a datum-less UTxO at the contract's staked form with 'UTxO not in wallet'. The deployed contract lets anyone spend that UTxO whatever its delegation part. I found no guard or earlier check that lets the staked form through, and no other caller or path that avoids it:
- The CLI's other spends (sweep, transfer) only take owned Register rows.
- The web wallet has no extract.
- CLI 0.4.10 and earlier, which compared against the staked form, can't help either: they build with a hardcoded 297-entry PlutusV3 cost model, and the network's has 350, so the script-data hash is wrong and the node refuses the transaction.
- The existing extract tests only feed the enterprise form.

The test fails on TREE with 'UTxO not in wallet'. It passes in a throwaway copy where the check compares network and payment part.

Grade: low, as the finder said.
- **Who:** the user, running `util extract` on such a UTxO. Reaching that state needs a datum-less payment to the staked form, which is an edge case. Routes in: another wallet paying an ADA Handle that still sits in a staked-form Seedelf UTxO from a CLI up to 0.4.10 (handles.ts:3-6 says pay-by-name pays the contract with no datum); Lovejoin's own withdraw UI to 'a Seedelf address' (chunk-16-lovejoin.md:90); or a hand payment to an address copied from an explorer.
- **Cost:** the CLI's documented rescue tool refuses. The money is already anyone's under the contract, so the CLI causes no loss itself; it only leaves the money exposed for longer.
- **Way out:** any third-party Plutus V3 builder can spend it, and so can anyone else. No Seedelf tool can.

The finder's 'since' holds for the staked form. The whole-address equality itself dates from 7c11e560/704b5834 (2025-01-10): up to 0.4.10 it compared against the staked form and so refused the enterprise form. 2c67e94c (first in tag 0.5.0) made wallet_contract the enterprise form, and the staked form has been refused from 0.5.0 through 0.7.0. HEAD's CLI code is 0.7.0's.

The fix adds no refusal and changes no privacy default, so it needs no call from the owner.

**Fix notes:**

**The fix (verified in the copy).** In seedelf-cli/src/commands/util/extract.rs:63-69, accept any Shelley address on this network whose payment part is the contract's script hash, instead of comparing whole addresses:

```rust
let contract = address::wallet_contract(network_flag, config.contract.wallet_contract_hash);
let ours = matches!((&utxo_addr, &contract), (Address::Shelley(u), Address::Shelley(c)) if u.network() == c.network() && u.payment() == c.payment());
if !ours { bail!("UTxO not in wallet"); }
```

- This widens acceptance to exactly what the contract accepts, so it adds no refusal, and the README row stays true.
- Move this test beside extract_rescues_empty_datum_utxo in tests/cli/extract.rs.
- The web wallet already compares payment hashes (wasm/src/decode.rs:827, cip30.rs:1349).
- Same blind spot in display: util history reads only the enterprise address (history.rs:34; R4 notes).

**Optional, separate from this finding.**
- extract.rs:60-62 also refuses any inline datum, though the contract makes a non-Register inline datum anyone's too. Widening that changes the README's 'no datum'.
- A datum-hash UTxO passes the inline check, but extract never attaches the datum, so it fails at evaluation. That's a harmless refusal; a fix could say so up front or attach the datum.

//! Chunk 51, finding r4#7: `util extract` must rescue a datum-less UTxO at the
//! wallet contract's staked form (its script hash with the [LOGIC] stake key),
//! where every CLI up to 0.4.10 paid the contract. The deployed contract
//! (5b82530, `validators/wallet.ak`) lets anyone spend a UTxO with no datum
//! (`None -> True`) and never reads the delegation part, so the address's
//! payment credential is what makes a UTxO the contract's.
//!
//! Drives the real `util extract` run against the CLI's offline mock Koios,
//! reusing `tests/cli/harness.rs` as is.

#[path = "cli/harness.rs"]
mod harness;

use pallas_addresses::{
    Address, Network, ScriptHash, ShelleyAddress, ShelleyDelegationPart, ShelleyPaymentPart,
    StakeAddress, StakeKeyHash,
};
use serial_test::serial;

use seedelf_cli::commands::util::extract::{ExtractArgs, run};
use seedelf_core::constants::PREPROD_STAKE_HASH;

use harness::*;

/// The contract's staked form on preprod: what `address::wallet_contract`
/// returned before 2c67e94c (0.5.0).
fn staked_wallet_contract() -> ShelleyAddress {
    ShelleyAddress::new(
        Network::Testnet,
        ShelleyPaymentPart::Script(ScriptHash::new(config().contract.wallet_contract_hash)),
        ShelleyDelegationPart::Key(StakeKeyHash::new(PREPROD_STAKE_HASH)),
    )
}

#[tokio::test]
#[serial]
async fn extract_rescues_a_datum_less_utxo_at_the_contracts_staked_form() {
    let staked = staked_wallet_contract();
    let Address::Shelley(enterprise) = wallet_address() else {
        panic!("the wallet contract is a Shelley address");
    };
    // The same script: only the delegation part differs.
    assert_eq!(staked.payment(), enterprise.payment());
    assert_ne!(Address::from(staked.clone()), wallet_address());

    // As Koios's utxo_info lists it: the full bech32, the stake address apart.
    let mut extracted = empty_datum_utxo(50, 2_000_000, &[]);
    extracted.address = staked.to_bech32().expect("staked bech32");
    extracted.stake_address = Some(
        StakeAddress::try_from(staked.clone())
            .expect("stake address")
            .to_bech32()
            .expect("stake bech32"),
    );

    let mut scenario = Scenario::start().await;
    scenario.mount_utxo_info(vec![extracted]).await;
    scenario
        .mount_address_utxos(vec![
            // a clean 5 ADA UTxO the command picks up as collateral
            address_utxo(&external_address_bech32(), 51, 5_000_000, &[]),
            address_utxo(&external_address_bech32(), 52, 10_000_000, &[]),
        ])
        .await;
    scenario.mount_evaluate(1).await;
    scenario.arm_web_capture();

    run(
        ExtractArgs {
            utxo: format!("{}#0", tx_hash(50)),
            address: external_address_bech32(),
        },
        PREPROD,
        VARIANT,
    )
    .await
    .expect("a datum-less UTxO at the contract's staked form is the contract's: extract should rescue it");

    let params = protocol_params().await;
    let tx = decode_tx(&scenario.captured_cbor());
    assert_sound_transaction(&tx, &scenario, &params);

    // The staked-form UTxO plus the funding UTxO are spent into one output.
    let mut inputs = tx.inputs.clone();
    inputs.sort();
    assert_eq!(inputs, vec![(tx_hash(50), 0), (tx_hash(52), 0)]);
    assert_eq!(tx.outputs.len(), 1);
    assert_eq!(tx.outputs_to(&external_address()).len(), 1);
    assert_eq!(tx.collateral, vec![(tx_hash(51), 0)]);
}
