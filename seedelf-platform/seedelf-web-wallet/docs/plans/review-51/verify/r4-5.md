**Fix notes:**

1. **Bind first. No owner call needed; the run checks it.**
   - Make `run_web_server` return `Result` and use `warp::serve(routes).try_bind_with_graceful_shutdown(addr, shutdown)`.
   - Call `display::webserver_address()` only after the bind succeeds.
   - On failure, return an error such as "Another signing page is already running at http://127.0.0.1:44203/: stop it first".
   - The same family has the print-then-bind order in three places: fund.rs:288-289, create.rs:301-302 and util/extract.rs:290-291. Each should drop its own `webserver_address()` call and pass the error up with `?`.
   - The capture seam's early return becomes `Ok(())`.
   - With exactly this sketch in a copy, r51_r4_5 passes.
2. **Per-run path, such as http://127.0.0.1:44203/<random token>/. No call needed.** This stops an earlier server from standing in for this run, but it does nothing for a stale tab, because that tab already holds the transaction in memory.
3. **The stale tab needs a page-side check, and that is the owner's call.**
   - Before `signTx`, the page re-fetches its transaction from its run's path. If the server is gone, or serves a different transaction, the page warns or refuses ("this page is from a run that has stopped: reload").
   - A warning fits the 2026-10-19 rule. A refusal declines a transaction the ledger accepts, so it needs the owner. One point for the owner: Ctrl-C is the user's own "stop", so declining to sign afterwards honours their choice rather than overriding it.
4. **Show the tx id on the page and in the terminal, and for fund the Seedelf and the amount**, so a user can match a page to its run. The CIP-30 prompt can't show this: every Seedelf pays the same enterprise script address under a re-randomized datum.

This is CLI-only and needs its own commit for a CLI patch release; the web wallet doesn't use this code.

/// Run `r51_r4_5_child_second_run` in a child process; its stdout and stderr,
/// ANSI colours stripped.
fn run_child(within: Duration) -> (String, String) {
    let mut child = Command::new(std::env::current_exe().expect("test binary"))
        .args([
            "--exact",
            "r51_r4_5_child_second_run",
            "--nocapture",
            "--test-threads=1",
        ])
        .env(CHILD, "1")
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .expect("start the second run");
    let mut out = child.stdout.take().expect("stdout");
    let mut err = child.stderr.take().expect("stderr");
    let out_reader = std::thread::spawn(move || {
        let mut s = String::new();
        let _ = out.read_to_string(&mut s);
        s
    });
    let err_reader = std::thread::spawn(move || {
        let mut s = String::new();
        let _ = err.read_to_string(&mut s);
        s
    });
    let deadline = Instant::now() + within;
    loop {
        if child.try_wait().expect("wait for the second run").is_some() {
            break;
        }
        if Instant::now() >= deadline {
            let _ = child.kill();
            let _ = child.wait();
            break;
        }
        std::thread::sleep(Duration::from_millis(100));
    }
    (
        strip_ansi(&out_reader.join().expect("stdout reader")),
        strip_ansi(&err_reader.join().expect("stderr reader")),
    )
}

/// GET `path` from the signing port: the transaction its page embeds, if any.
fn fetch_tx(path: &str) -> std::io::Result<Option<String>> {
    let mut stream = TcpStream::connect(HOST)?;
    stream.set_read_timeout(Some(Duration::from_secs(10)))?;
    write!(
        stream,
        "GET {path} HTTP/1.1\r\nHost: {HOST}\r\nConnection: close\r\n\r\n"
    )?;
    let mut response = String::new();
    stream.read_to_string(&mut response)?;
    const KEY: &str = r#"{ "message": ""#;
    Ok(response.find(KEY).map(|i| {
        let rest = &response[i + KEY.len()..];
        rest[..rest.find('"').unwrap_or(rest.len())].to_string()
    }))
}

fn wait_for_tx_at(path: &str, within: Duration) -> Option<String> {
    let deadline = Instant::now() + within;
    while Instant::now() < deadline {
        if let Ok(Some(tx)) = fetch_tx(path) {
            return Some(tx);
        }
        std::thread::sleep(Duration::from_millis(100));
    }
    None
}

/// The path of the signing URL a run announced: a line holding the bare URL,
/// as `display::webserver_address` prints it.
fn announced_path(stdout: &str) -> Option<String> {
    stdout.lines().map(str::trim).find_map(|line| {
        let path = line.strip_prefix(URL_PREFIX)?;
        if path.contains(char::is_whitespace) {
            return None;
        }
        Some(if path.is_empty() { "/".to_string() } else { path.to_string() })
    })
}

fn line_after(text: &str, prefix: &str) -> Option<String> {
    text.lines()
        .map(str::trim)
        .find_map(|l| l.strip_prefix(prefix).map(|rest| rest.trim().to_string()))
}

/// A transaction's id and what it pays the wallet contract, and to whom.
fn describe(cbor: &str) -> String {
    let id = hex::decode(cbor)
        .ok()
        .and_then(|bytes| MultiEraTx::decode(&bytes).ok().map(|tx| tx.hash().to_string()))
        .unwrap_or_else(|| "undecodable".to_string());
    let paid = decode_tx(cbor)
        .outputs_to(&wallet_address())
        .iter()
        .map(|o| {
            let owner = match &o.register {
                Some(r) if r.is_owned(owner_a()).unwrap_or(false) => "Seedelf A's owner",
                Some(r) if r.is_owned(owner_b()).unwrap_or(false) => "Seedelf B's owner",
                _ => "neither owner",
            };
            format!(
                "{} lovelace to {} for {owner}",
                o.lovelace,
                o.address.to_bech32().unwrap_or_default()
            )
        })
        .collect::<Vec<_>>()
        .join("; ");
    format!("tx {id}, {paid}")
}

fn strip_ansi(s: &str) -> String {
    let mut out = String::with_capacity(s.len());
    let mut chars = s.chars().peekable();
    while let Some(c) = chars.next() {
        if c != '\u{1b}' {
            out.push(c);
            continue;
        }
        if chars.peek() == Some(&'[') {
            chars.next();
            for n in chars.by_ref() {
                if n.is_ascii_alphabetic() {
                    break;
                }
            }
        }
    }
    out
}
