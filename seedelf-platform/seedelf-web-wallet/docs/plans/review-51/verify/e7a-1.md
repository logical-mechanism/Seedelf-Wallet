## Impact: partly, low

The defect is real. I traced it end to end: buildOut keeps only { summary, quote, lovejoin }, the approval takes the form's live `pay` and `get`, and while the first build runs nothing disables the token cards or the Switch. But the impact is narrower than medium, for five reasons.

(1) Only the user can reach it, and only by racing their own build. They have to finish a pick (the picker, or one press of the Switch) in the few seconds between pressing Review swap and the review appearing. That's about 1–5 s, up to about 10 s with Koios retries. Only this first build counts: the approval's own rebuilds (the switch, Change, Build again) run with the form unmounted, so the picks can't move then. If the build finishes while the picker is still open, the picker unmounts and nothing changes. setPay and setGet are called only from flip() and choose(), so only clicks change them. No stranger or site can touch them.

(2) Nothing is lost, locked, stranded or misdirected. What runs is exactly the ADA→MIN swap the user set up and pressed Review for, at its quote and under its approved minimum. The approval's money figures are the build's and are right: the funding rows, the fee, the total leaving, the balance after and the costs. Only token names and token decimals come from the live picks: the header, the 'at least' foot, the unlisted line, the minimum callout and 'Comes back'.

(3) The true pair is named at once, and there is a way out. Start swap goes straight to the swap's own page, titled from the record: '100 ₳ → MIN', with 'Quoted: about 906.5941 MIN'. Home's row and the history name MIN too. Stop stays offered through funding, ordering and filling. The order goes out only after the funding's block and the runner's next pass (a 1-minute alarm), and then waits for a batcher. Stop before the order costs the return's network fee (about 0.25 ₳) beside the funding fee already paid; the dialog offers the direct way once its cost read lands (e7a#2 covers the case where it doesn't). After the order, the cancel is capped at 3 ₳. If the user misses all of it, they hold MIN worth the swap at market. Getting to X then costs one more swap: about 2 ₳ of DEX fee, Minswap's fee, about 0.75 ₳ of network fees and Lovejoin's costs. That's a few ₳, whatever the size, plus that swap's price impact.

(4) It isn't the high class 'signs something other than what it shows'. The funding signed at Start is exactly its rows. The order is the recorded pair. The mismatch is mislabelling that the user's own race causes, and no attacker can drive it.

(5) Precedent: 1.8.0 left a race-only wording issue as it was ('lj.bringOtherPool'), and 1.6.0's 320-screens#4 set the rule that a review shows what it was built at.

So it fits 'a small cost in an edge case'. The finder's since (e43cec9a, before 1.0.0) holds.
