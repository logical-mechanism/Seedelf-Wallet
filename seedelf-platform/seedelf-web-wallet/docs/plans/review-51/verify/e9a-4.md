## Trace: confirmed, low

The finding holds as described. I couldn't refute it. A Make private sent from this device, once Koios lists it, is written in Public activity's CSV as "Made private". A Make public to the user's own account is written "Made public". Both names come from the sealed private history. The note right under Save as CSV says "The file isn't encrypted, though everything in it is on the chain anyway."

The chain alone reads the same two transactions as "Sent" to the wallet contract's address and "Received" from it. That is the reading the same `describe` gives on any device without this one's records, for example after a restore. privacy.md:99 and :129 say a Make private looks, from outside, the same as paying someone else's Seedelf. So the file tells whoever holds it something the chain doesn't: that those deposits went into the user's own private balance, and that those contract UTxOs were the user's own when spent.

I found no guard. `exported` drops only pending rows. Nothing on the public side strips or renames the device-named rows. privacy.md's *Save as CSV* section and the policy's row cover the private side only, and privacy-notes.test.ts:39-42 pins the public wording as it stands.

The consequence is a little narrower than the scenario's "the later private spends can be followed". privacy.md:98 and :148 already say the chain links the account to the UTxOs a Make private creates, and leads from the account to later spends of that money. What the file adds is certainty: it removes the "maybe someone else's Seedelf" doubt. It is not a new path.

It isn't known. privacy-review §2.21 fixed the private note only. §4.6 names "the public Activity's labels on old move-ins" only as a cost of clearing history. Nothing in the backlog, the review records, the policy or SECURITY.md settles it.

Grade: low.
- Who: the user, by an ordinary action (Save as CSV on Public activity, on the device that made the move-ins), then giving the file to an accountant or a tax tool.
- Cost: no money. A privacy cost: ownership of deposits whose link to the account is already on chain becomes certain.
- Way out: don't share the file. The note is what tells the user it's safe to share.

// Chunk 51, e9a#4: Public activity's Save as CSV note says "The file isn't encrypted, though everything in it is on the
// chain anyway." On the device that made them, though, the file names the user's own Make private and Make public to
// the account from the sealed private history ("Made private", "Made public"), where the chain alone reads a payment
// into the wallet contract ("Sent") and one out of it ("Received"): from outside, a Make private looks the same as
// paying someone else's Seedelf (privacy.md, Making money private). Whatever the note says must hold of the file: while
// it says the chain has everything in it, each row says what the chain does.
import { createElement } from "react";
import { renderToStaticMarkup } from "react-dom/server";
import { describe, expect, it } from "vitest";

import { accountMatcher, describe as describeTxs, SESSION_ACCOUNT_ADDRESSES_PREFIX, type AccountAddresses } from "../src/background/activity";
import { txInputs } from "../src/background/cbor";
import type { KoiosTxInfo } from "../src/background/koios";
import { activityCsv, activityTitle } from "../src/ui/activity";
import { ExportNote } from "../src/ui/screens/Activity";
import { activityPreprod, koiosPreprod, testBalances, vectors } from "./fakes";

const PASSWORD = "correct horse battery";
/** What a person reads. */
const text = (html: string) =>
  html
    .replace(/<[^>]+>/g, " ")
    .replaceAll("&#x27;", "'")
    .replace(/\s+/g, " ")
    .trim();
/** A row's Type, the CSV's second column: none of these rows quotes a cell before it. */
const typeIn = (csv: string, txHash: string) => csv.split("\r\n").find((row) => row.endsWith(txHash))?.split(",")[1];

describe("r51 e9a#4: Public activity's CSV against its note", () => {
  it("writes the user's own Make private and Make public as the chain reads them while the note says it's all on chain", async () => {
    // On a chain tip like preprod's, and the device's real clock (activity.test.ts's onPreprod).
    const v = vectors("cardano_account.json").find((v) => v.account === 0 && v.phrase.split(" ").length === 12)!;
    const t = testBalances();
    t.koios.tip = 106_000_000;
    t.clock.now = Date.now();
    await t.wallet.create(v.phrase, PASSWORD);
    await t.balances.get("preprod");
    const account = (await t.session.get<AccountAddresses>(`${SESSION_ACCOUNT_ADDRESSES_PREFIX}preprod`))!;
    const own = { bech32: account.addresses[0]!, cred: account.keys[0]! };
    const contract = { bech32: koiosPreprod.contract_utxos[0]!.address, cred: koiosPreprod.wallet_contract };
    const top = activityPreprod.account_txs[0]!;

    // Make private, 20 ₳, sent from this device: its submit notes it in the sealed private history.
    const moveIn = await t.moveIn.build("preprod", "20000000", []);
    await t.moveIn.submit("preprod", moveIn.txHash);
    // In a block: the account's coins in; the deposit at the wallet contract, the change back, the rewards collected.
    const inputs = txInputs(t.koios.submitted[0]!);
    const spent = koiosPreprod.accounts[activityPreprod.stake]!.account_utxos.filter((u) => inputs.includes(`${u.tx_hash}#${u.tx_index}`));
    expect(spent).toHaveLength(inputs.length);
    const madePrivate: KoiosTxInfo = {
      tx_hash: moveIn.txHash,
      block_height: top.block_height + 1,
      tx_timestamp: top.block_time + 60,
      fee: moveIn.fee,
      inputs: spent.map((u) => ({ payment_addr: { bech32: u.address, cred: u.payment_cred }, value: u.value, asset_list: u.asset_list ?? [] })),
      outputs: [
        { payment_addr: contract, value: "20000000", asset_list: [] },
        { payment_addr: own, value: moveIn.changeLovelace, asset_list: spent.flatMap((u) => u.asset_list ?? []) },
      ],
      withdrawals: moveIn.withdrawal ? [{ amount: moveIn.withdrawal, stake_addr: activityPreprod.stake }] : [],
    } as KoiosTxInfo;

    // Make public, 10 ₳ to the account's own address (the form warns, and lets it go): noted as its submit notes it
    // (pending.ts submitWatched → ActivityService.sent, with WithdrawSummary's payments and fee).
    const withdrawHash = "cd".repeat(32);
    await t.activity.sent(
      "preprod",
      { kind: "withdraw", network: "preprod", txHash: withdrawHash, submittedAt: t.clock.now, confirmations: null },
      { payments: [{ address: own.bech32, lovelace: "10000000", tokens: [] }], fee: { total: "250000" } },
    );
    // On chain: a contract UTxO spent, 10 ₳ to the account, the change back into the contract.
    const madePublic: KoiosTxInfo = {
      tx_hash: withdrawHash,
      block_height: top.block_height + 2,
      tx_timestamp: top.block_time + 120,
      fee: "250000",
      inputs: [{ payment_addr: contract, value: "30000000", asset_list: [] }],
      outputs: [
        { payment_addr: own, value: "10000000", asset_list: [] },
        { payment_addr: contract, value: "19750000", asset_list: [] },
      ],
    } as KoiosTxInfo;

    // Koios lists both under the account's key, as credential_txs does.
    t.koios.credentialTxs.set(own.cred, [
      { tx_hash: withdrawHash, block_height: madePublic.block_height, block_time: madePublic.tx_timestamp },
      { tx_hash: moveIn.txHash, block_height: madePrivate.block_height, block_time: madePrivate.tx_timestamp },
    ]);
    t.koios.txRows.set(moveIn.txHash, madePrivate);
    t.koios.txRows.set(withdrawHash, madePublic);

    // Public activity on this device, and its Save as CSV: both in a block, so both in the file.
    const { entries, more } = await t.activity.cardano("preprod");
    const listed = entries.filter((e) => e.txHash === moveIn.txHash || e.txHash === withdrawHash);
    expect(listed).toHaveLength(2);
    expect(listed.every((e) => !e.pending)).toBe(true);
    const csv = activityCsv("preprod", entries);
    const note = text(renderToStaticMarkup(createElement(ExportNote, { of: "cardano", listed: entries.length, more })));

    // What the chain alone says of the same transactions: what any device without this one's records writes.
    const chain = describeTxs([madePrivate, madePublic], accountMatcher(account), new Map(), account.stake);
    expect(chain.map((e) => [activityTitle(e), e.detail])).toEqual([
      ["Sent", contract.bech32],
      ["Received", contract.bech32],
    ]);
    const chainSays = chain.map(activityTitle);
    const fileSays = [typeIn(csv, moveIn.txHash), typeIn(csv, withdrawHash)];

    // The note's claim, checked against the file: while it says everything in it is on the chain, the rows say only what
    // the chain does. Today the note says so, and the file says "Made private" and "Made public".
    const claimsChainOnly = note.includes("everything in it is on the chain anyway");
    expect(claimsChainOnly ? fileSays : chainSays, `the note: "${note}"`).toEqual(chainSays);
  });
});
