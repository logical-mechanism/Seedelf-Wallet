# r2a#2: verification

From lane R2a, graded low by its finder.

## Trace: confirmed, low

The finding holds as described, and a run confirms it. apart() ends its search at the first merging order whose full set is short (build.rs:2843-2846, `Grown::Short if whole => { failed = false; break; }`). That shortcut assumes that if everything together is short, every subset is. A UTxO whose tokens need more change than it holds breaks that assumption.

The case I ran:
- Balance: O1, 20 ₳ made private (Own); B1 and B2, two Lovejoin boxes of 9.71 ₳; D, a stranger's 200 one-byte-named tokens at their on-chain least of 4,068,640 lovelace (Received).
- Payment: 35 ₳ to an address (Purpose::Pay).
- All four together are short: their change must carry D's tokens 20 to an output, which needs 18,576,100 lovelace.
- O1 + B1 + B2 pay it, with fee 329,710 and 4,090,290 lovelace of ADA-only change.
- sweep_many, the CLI's order, pays it with exactly those three.
- sweep_many_apart refuses it with "Not enough ADA". Orders b, c (j = 2 gives [B1, B2, O1]) and d (the CLI's order) never run.

With only the break removed, in a copy outside TREE, the same test passes.

The web wallet gives no way around it:
- Make public reaches sweep_many_apart through buildWithdrawParts, build_withdraw and withdraw_spend.
- WebAssembly's fallback, measured_or_more, takes max_inputs by lovelace (all four, D included), so it is short too.
- build_withdraw_parts returns a short as it is, with no parts.
- The extension then tells the user they can pay "up to about" Max's figure (about 24.4 ₳ by trace), "since 18.58 ₳ has to stay with the tokens you keep. Send them too to free it".

This breaks the promise in build.rs:2316-2318 and 2533-2534, privacy.md:171 and independent-review M6: never refuse what the CLI's order pays.

Graded low, as the finder graded it:
- Who: a stranger who pays more than 20 tokens in one output, close to their least. A deliberate one spends about 4.1 ₳, and that money goes to the victim.
- When: only where histories are known. The CLI and a restored wallet with no history pick the CLI's way and pay.
- Cost: a payment the balance can make in one transaction is refused. For this shape that's roughly every amount from about 24.3 ₳ to about 37.6 ₳, worked out from the run's figures. The refusal's figures are off by about 14 ₳.
- Nothing is lost, locked or misdirected by the refusal itself.
- Way out: lock D in coin control (a locked UTxO is left out of every spend on that side), or pay in pieces. The refusal's words don't point there.
- The heavier cost, the user's ADA bound as the tokens' least once they do pay with the bundle, is r2a#3's.

One side claim is narrower than stated. The scenario says "Even with r2a#3 fixed … a window of about 0.16 ₳ stays refused". For a single bundle that is only the exact-change point, not a 0.16 ₳ range: the subset's ADA-only change must be 0 or at least an ADA-only contract output's least (stage, build.rs:2147-2153, about 1.46 ₳). Meanwhile the whole set is short only while that change is under about 0.17 ₳ (the 120,680-lovelace base-address premium plus the input's fee). A range comes back only with several such bundles. This doesn't change the verdict on TREE.

The fix, run against the test:

Caveats for whoever fixes it:
- Without the break, a later order's Failed sets failed = true (2849-2852). The final error then becomes `other` (TooMany or TooLarge) rather than not_enough. In the web wallet that sends the payment to the parts planner (lib.rs:4793) instead of the short refusal. Decide which should win.
- A truly short payment whose total passes the floor costs more estimates. They're bounded by orders × UTxOs, each a settle loop.
- I didn't run apart_test.rs against the mutant, by the brief's one-test rule. By trace, what_no_order_pays_is_still_refused still passes: its 100 ₳ case never passes the floor, and its 40 ₳ case ends Failed with TooMany.

The same class elsewhere (traced, not run):

- Fundings (Purpose::Fund) share it too, with no fallback (lib.rs:3571 excludes funding), and there Received money ranks first.
- measured_or_more (lib.rs:3198-3213) re-picks by max_inputs's lovelace order, which takes such a bundle as well.
- Worth::adds (lib.rs:3721-3731) saturates at 0.
- r2a#3's fix (price what a UTxO adds as its ADA less its tokens' change, keeping the sign; pack change by size) is the class fix. It shrinks the window, but for one bundle what's left is only the exact-change point, not the finder's 0.16 ₳ range.

//! Chunk 51, finding r2a#2: `apart` ends its search at the first order grown
//! whole that's short (build.rs `Grown::Short if whole => { failed = false;
//! break; }`), on the premise "short with everything is short in any order"

//! build.rs's section comment and privacy.md ("It never refuses a payment the
//! CLI's order would make").
//!
//! The state: 20 ₳ made private (Own), two boxes back from Lovejoin, and a

/// About what a box back from Lovejoin brings: 10 ₳ less the withdraw's fee.

fn chain() -> Chain {

    Chain {
        params: ProtocolParameters::from_koios(&rows[0]).unwrap(),

struct World {
    chain: Chain,
    owner: Register,
    wallet: Address,
    signer: Hash<28>,
}

fn world() -> World {
    let chain = chain();
    let key = SecretKey::new(OsRng);
    World {
        wallet: wallet_contract(true, chain.config.contract.wallet_contract_hash),
        chain,
        owner: Register::create(random_scalar()).unwrap(),
        signer: Hasher::<224>::hash(PrivateKey::from(key).public_key().as_ref()),
    }
}

/// A wallet-contract UTxO owned by `w`, made by the transaction `[a, b; 32]`,
/// holding one of each token named in `names` (raw bytes), as Koios returns it.
fn owned(w: &World, a: u8, b: u8, lovelace: u64, names: &[Vec<u8>]) -> UtxoResponse {
    let register = w.owner.clone().rerandomize().unwrap();
    let mut hash = [a; 32];
    hash[31] = b;
    UtxoResponse {
        tx_hash: hex::encode(hash),
        tx_index: 0,
        address: w.wallet.to_bech32().unwrap(),
        value: lovelace.to_string(),
        payment_cred: hex::encode(w.chain.config.contract.wallet_contract_hash),
        inline_datum: Some(InlineDatum {
            bytes: hex::encode(register.to_vec().unwrap()),
            value: json!({
                "constructor": 0,
                "fields": [{"bytes": register.generator}, {"bytes": register.public_value}]
            }),
        }),
        asset_list: Some(
            names
                .iter()
                .map(|name| KoiosAsset {
                    decimals: 0,
                    quantity: "1".to_string(),
                    policy_id: TOKEN_POLICY.to_string(),
                    asset_name: hex::encode(name),
                    fingerprint: String::new(),
                })
                .collect(),
        ),
        ..Default::default()
    }
}

/// The least the ledger takes for one output at the contract's (enterprise)
/// address holding one of each of `names` under an inline register: what a
/// stranger pays the Seedelf at the least.
fn least_on_chain(w: &World, names: &[Vec<u8>]) -> u64 {
    let policy: [u8; 28] = hex::decode(TOKEN_POLICY).unwrap().try_into().unwrap();
    let register = w.owner.clone().rerandomize().unwrap();
    let mut output =
        Output::new(w.wallet.clone(), 5_000_000).set_inline_datum(register.to_vec().unwrap());
    for name in names {
        output = output.add_asset(Hash::new(policy), name.clone(), 1).unwrap();
    }
    calculate_min_required_utxo(output, &w.chain.params).unwrap()
}

fn class(id: &str, origin: Origin) -> Class {
    Class {
        id: id.into(),
        origin,
    }
}

fn histories(purpose: Purpose, utxos: &[(&UtxoResponse, Class)]) -> Histories {
    utxos.iter().fold(Histories::new(purpose), |h, (u, c)| {
        h.with(&u.tx_hash, u.tx_index, c.clone())
    })
}

fn pay(lovelace: u64) -> Vec<AddressPayment> {
    vec![AddressPayment {
        to: ShelleyAddress::new(
            Network::Testnet,
            ShelleyPaymentPart::Key(PaymentKeyHash::new([7; 28])),
            ShelleyDelegationPart::Null,
        )
        .into(),
        lovelace,
        tokens: Assets::new(),
    }]
}

fn outpoints(utxos: &[UtxoResponse]) -> Vec<String> {
    let mut v: Vec<String> = utxos
        .iter()
        .map(|u| format!("{}#{}", u.tx_hash, u.tx_index))
        .collect();
    v.sort();
    v
}

#[test]
fn a_payment_the_clis_order_makes_is_not_refused_for_a_bundle_that_costs_more_than_it_adds() {
    let w = world();
    let names: Vec<Vec<u8>> = (0..200u16).map(|i| vec![i as u8]).collect();
    let d_least = least_on_chain(&w, &names);

    let o1 = owned(&w, 0x01, 0, 20 * ADA, &[]);
    let b1 = owned(&w, 0xb0, 0, BOX, &[]);
    let b2 = owned(&w, 0xb0, 1, BOX, &[]);
    let d = owned(&w, 0xd0, 0, d_least, &names);
    let available = vec![o1.clone(), b1.clone(), b2.clone(), d.clone()];
    // As the extension classes them (activity.ts `classes`): money made
    // private, each box its own, a stranger's payment received.
    let h = histories(
        Purpose::Pay,
        &[
            (&o1, class("public", Origin::Own)),
            (&b1, class(&format!("box:{}", b1.tx_hash), Origin::Lovejoin)),
            (&b2, class(&format!("box:{}", b2.tx_hash), Origin::Lovejoin)),
            (&d, class(&format!("received:{}", d.tx_hash), Origin::Received)),
        ],
    );
    let payment = pay(35 * ADA);

    // D's tokens re-made as change, 20 to an output, need more than D holds.
    let d_tokens = names.iter().fold(Assets::new(), |all, n| {
        all.add(Asset::new(TOKEN_POLICY.to_string(), hex::encode(n), 1).unwrap())
            .unwrap()
    });
    let kept = build::minimum_deposit(&w.chain.params, &d_tokens).unwrap();
    println!("D holds {d_least} lovelace (its least on chain); its tokens as change need {kept}");
    assert!(kept > d_least);

    // Everything together is short ...
    let whole = build::sweep_many_from(&w.chain, &available, &payment, &w.owner, w.signer)
        .unwrap()
        .estimate();
    let e = whole.err().expect("all four together pay");
    println!("O1 + D + B1 + B2: {e} (is_short = {})", build::is_short(&e));
    assert!(build::is_short(&e), "{e}");

    // ... while O1 and the two boxes pay it, with change of ADA alone.
    let subset = vec![o1.clone(), b1.clone(), b2.clone()];
    let paid = build::sweep_many_from(&w.chain, &subset, &payment, &w.owner, w.signer)
        .unwrap()
        .estimate()
        .expect("O1 + B1 + B2 pay 35 ₳");
    println!(
        "O1 + B1 + B2: fee {} lovelace, change {} lovelace, change tokens {}",
        paid.fee.total,
        paid.change_lovelace,
        paid.change_tokens.items.len()
    );

    // The CLI's order (sweep_many: no histories) makes exactly that payment.
    let blind = build::sweep_many(&w.chain, &available, &payment, &w.owner, w.signer)
        .expect("the CLI's order pays 35 ₳");
    assert_eq!(outpoints(&blind.inputs()), outpoints(&subset));
    println!("sweep_many (the CLI's order): Ok, spends O1, B1, B2");

    let apart = build::sweep_many_apart(&w.chain, &available, &h, &payment, &w.owner, w.signer);

        Err(e) => println!("sweep_many_apart: Err({e}), is_short = {}", build::is_short(e)),
    }

        .unwrap_or_else(|e| panic!("refused a payment the CLI's order makes: {e}"))
        .inputs();
    // O1, B1 and B2 are the only UTxOs that pay it.
    assert_eq!(outpoints(&spent), outpoints(&subset));
}
