# w1b#2: verification

From lane W1b, graded low by its finder.

## Trace: confirmed, low

The finding holds as its title says. A Seedelf UTxO that also holds other tokens is listed as the user's, and Remove pays those tokens to the chosen destination. Neither RemoveResult, RemoveSummary, the Remove review nor the Seedelf card (SeedelfInfo) names them.

Every step of the stranger's path goes through:
- At 5b82530, the deployed policy checks only the minted token's name and amount, and wallet.ak checks only the proof and the signer. So anyone can put a Seedelf (freshly minted, or their own moved) plus any tokens under a copy of a register the user owns. Every Seedelf's register is public through its name.
- Both contract-scan paths (Koios and the private index) mark that UTxO owned and keep its tokens. balances.ts lists it with its ADA only.
- remove_spend and seedelf_in let other policies' tokens through. The change, tokens included, goes to `to`. remove_result keeps only `change_lovelace`.

My test shows it: all 100 foreign tokens go to account 0/0, and the result names no token.

One correction: the tokens do not "appear nowhere". The UTxOs screen's private list shows the planted UTxO as "3 ₳ and 1 token" with the Seedelf tag, and its details list the token (coin-control.ts:307-316, Utxos.tsx:244-245 and :380). The review's Transaction details button shows them too.

Grade: low.
- **Who:** a stranger.
- **Cost to the user:** none. The removal spends only the planted UTxO, with giveme.my's collateral. The fee and the tokens' minimum ADA come out of the gift. The review's ADA figure is exact: 2.755846 ₳ = 3 ₳ − 0.244154 ₳. Tokens and ADA both land on the user's own side, account 0/0 or the private balance.
- **Privacy:** no new link. The removal's own output already ties the Seedelf to where it goes.
- **Way out:** the tokens can be seen before signing, on the UTxOs screen and in Transaction details.
- **Own flows:** the wallet's own mints never make this shape (build.rs:3044-3047 and 3899-3902 put only ADA and the Seedelf token in the output). Only a stranger, or another tool using the same key, can.

It is not a high "signs other than it shows": what the review shows is true, it is just incomplete, and the extra goes to the user.

//! Chunk 51, finding w1b#2: removing a Seedelf whose UTxO also holds another
//! token pays that token to the removal's destination, but `RemoveResult`,
//! which the worker turns into Remove's review, never names it.
//!
//! Anyone can make such a UTxO: the deployed policy (seedelf.ak at 5b82530)
//! checks only the minted name, and the wallet validator only the proof, so a
//! stranger can put a Seedelf plus tokens of their choice under a register the
//! user owns, and the wallet lists it among the user's Seedelfs.
//!
//! The right behaviour: the result names every token the removal moves, as
//! every other result whose change goes somewhere the user picked does
//! (`WithdrawResult`'s Max payment reports `built.change_tokens`). It fails
//! today because `remove_result` keeps only `built.change_lovelace`.

use pallas_traverse::MultiEraTx;
use seedelf_crypto::cardano::{CardanoAccount, Role};
use seedelf_crypto::derivation::seedelf_key_v1;
use seedelf_koios::koios::{Asset, UtxoResponse};
use seedelf_wasm::api::{self, RemoveRequest};
use serde_json::Value;

const PHRASE: &str = "abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about";

/// A stranger's token, under a policy nothing else in the request uses.
const JUNK_NAME: &str = "6a756e6b"; // "junk"
const JUNK_QUANTITY: u64 = 100;

fn junk_policy() -> String {
    "cd".repeat(28)
}

fn fixture(path: &str) -> Value {
    let path = format!("{}/{path}", env!("CARGO_MANIFEST_DIR"));
    serde_json::from_str(&std::fs::read_to_string(path).unwrap()).unwrap()
}

fn params() -> Value {
    fixture("../../seedelf-core/tests/fixtures/epoch_params.json")[0].clone()
}

/// The fixture's Seedelf UTxO (the web-wallet register's, holding one Seedelf),
/// with 100 of the stranger's token beside it and 3 ₳, enough for an address
/// output carrying that token after the fee.
fn seedelf_with_junk() -> UtxoResponse {
    let owned: Vec<UtxoResponse> = serde_json::from_value(
        fixture("../extension/tests/fixtures/owned-utxos.json")["owned_utxos"].clone(),
    )
    .unwrap();
    let mut utxo = owned.into_iter().last().unwrap();
    assert_eq!(
        utxo.asset_list.as_ref().map(Vec::len),
        Some(1),
        "the fixture's Seedelf UTxO holds its Seedelf alone"
    );
    utxo.value = "3000000".into();
    utxo.asset_list.as_mut().unwrap().push(Asset {
        decimals: 0,
        quantity: JUNK_QUANTITY.to_string(),
        policy_id: junk_policy(),
        asset_name: JUNK_NAME.into(),
        fingerprint: String::new(),
    });
    utxo
}

/// The account's receive address 0/0 on preprod: where withdraw.ts's
/// `buildRemove` sends a removal "to the account".
fn own_address() -> String {
    CardanoAccount::from_phrase(PHRASE, 0)
        .unwrap()
        .base_address(true, Role::Receive, 0)
        .unwrap()
        .to_bech32()
        .unwrap()
}

/// How much of the junk token the transaction's outputs pay to `to`.
fn junk_paid_to(tx_cbor: &str, to: &str) -> u64 {
    let bytes = hex::decode(tx_cbor).unwrap();
    let tx = MultiEraTx::decode(&bytes).unwrap();
    let policy = junk_policy();
    let name = hex::decode(JUNK_NAME).unwrap();
    let mut paid = 0;
    for output in tx.outputs() {
        if output.address().unwrap().to_bech32().unwrap() != to {
            continue;
        }
        let value = output.value();
        for group in value.assets() {
            if hex::encode(group.policy()) != policy {
                continue;
            }
            for asset in group.assets() {
                if asset.name() == name.as_slice() {
                    paid += asset.output_coin().unwrap();
                }
            }
        }
    }
    paid
}

#[test]
fn a_removal_names_the_tokens_it_moves() {
    let sk = seedelf_key_v1(PHRASE, 0).unwrap();
    let to = own_address();
    let request = RemoveRequest {
        network: "preprod".into(),
        params: params(),
        utxo: seedelf_with_junk(),
        to: Some(to.clone()),
        seed: None,
        evaluation: None,
    };
    // Built as the worker builds it: measured in the wallet, then shown.
    let result = api::build_remove(sk, request).unwrap();

    // What the transaction does: the stranger's 100 tokens go to `to` with
    // the ADA. (This holds today.)
    assert_eq!(
        junk_paid_to(&result.tx_cbor, &to),
        JUNK_QUANTITY,
        "the removal pays the UTxO's other token to its destination"
    );

    // What the worker and the review get: every field but the transaction's
    // own bytes, hash and seed. It must name the token it moves.
    let mut shown = serde_json::to_value(&result).unwrap();
    let fields = shown.as_object_mut().unwrap();
    for raw in ["txCbor", "txHash", "seed"] {
        fields.remove(raw);
    }
    let shown = shown.to_string();
    assert!(
        shown.contains(&junk_policy()) && shown.contains(JUNK_NAME),
        "the removal moves {JUNK_QUANTITY} of {}.{JUNK_NAME} to {to}, \
         but its result names no token: {shown}",
        junk_policy()
    );
}
