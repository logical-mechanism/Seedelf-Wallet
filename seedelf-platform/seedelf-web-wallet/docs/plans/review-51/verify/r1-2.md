## Trace: confirmed, medium

It holds as described.

What happens:
- `submit_tx` (koios.rs:553-561) answers a gateway 504 with the same first words as a node's 400 refusal: "Koios rejected the transaction".
- It answers the client's 30 s timeout with the same first words as a connection that never opened: "Failed to submit transaction".
- In both cases the CLI prints no transaction id and exits.
- Once the first transaction lands, running the same `transfer` again spends its change and pays the recipient a second time.

How it was shown:
- The test drives the real `transfer::run` against tests/cli's mock Koios.
- It shows 4,000,000 lovelace reaching a stranger's Seedelf for one 2,000,000 payment.
- It then fails on the assertion that a maybe-sent submit must be told apart from a not-sent one.
- With a minimal fix in a copy, the same test passes.

Where the finding says a little more than the code:
- Only `transfer` and `sweep --lovelace/--asset` can repeat their payment on a re-run.
- `util mint` would mint a second Seedelf. It costs one more fee, and the Seedelf's ADA stays the user's.
- `remove`, `sweep --all` and `external sweep` find the Seedelf or the funds already gone.
- "Nothing to look up" goes too far: spend.rs:86-89 and external/sweep.rs:56-59 print the full signed CBOR before submitting. But the CLI never prints the id and has no command that gives it.

Why medium and not low:
- Any CLI user can reach it, when Koios's gateway or the network fails after Koios has taken the transaction. That is infrequent, and no stranger or site can cause it.
- But the cost is the whole payment again, paid to someone else. The error says the opposite of a warning, and once paid there is no way back.
- The scale's medium is "a user's ordinary action loses or overpays money with no warning", and the action here is running the command again after it reported a failure. Low is for a *small* cost.
- The wallet's own copy of this class was graded Medium (launch-review #10).

The code is the same at CLI tag 0.7.0. So it's within SECURITY.md's scope as a loss of funds that isn't solely the user's error.

**Fix notes:**

**1. Fix the class in `submit_tx`** (seedelf-koios/src/koios.rs:547-567) by porting the extension's `submitTx` classification (extension/src/background/koios.ts:1183-1284).
- **Not sent:**
  - a connect error (reqwest's `is_connect()`);
  - a 429;
  - a body naming `TxSubmitConnectionError`: the instance's node was down.
- **May have gone through:**
  - any other transport error once the request has started: `is_timeout()`, or a connection lost mid-request;
  - any 5xx, as the extension treats ≥500;
  - a 2xx whose body can't be read in time or isn't JSON (koios.rs:563-566);
  - a 2xx that isn't a bare string (fee.rs:21-28 today says "Koios rejected the transaction: {response}"; independent-review L2's case).
- **Refused:** any other 4xx, carrying the node's own words.
  - Today `error_for_status()` drops the body, so even a real refusal shows only "400 Bad Request".

```
//! Chunk 51, finding r1#2: the CLI's submit reads "Koios took the transaction
//! but never answered" as not sent.
//!
//! `seedelf_koios::koios::submit_tx` puts every outcome but a 2xx into two
//! errors: "Koios rejected the transaction" (any 4xx or 5xx) and "Failed to
//! submit transaction" (no answer at all). So a gateway 504, or the client's
//! own 30 s timeout, after Koios has the transaction reads the same as the
//! node refusing it, or as a connection that never opened, and the CLI prints
//! no transaction id. The transaction can still land, and `transfer` run again
//! once it has spends its change and pays the recipient a second time.
//!
//! Part 1 drives the real `transfer` against tests/cli's mock Koios (its
//! harness is included here unchanged) to show that, and checks only its own
//! preconditions. Part 2 is the assertion: `submit_tx`'s own words (its
//! outermost message, the one the CLI's `Error:` line starts with) for a
//! submit that may have gone through must not be the words it uses for one
//! that didn't. It fails today for both the 504 and the timeout.

#[path = "cli/harness.rs"]
mod harness;

use std::time::Duration;

use harness::*;
use pallas_traverse::MultiEraTx;
use seedelf_cli::commands::transfer::{TransforArgs, run};
use seedelf_crypto::schnorr::random_scalar;
use seedelf_koios::koios::{UtxoResponse, override_endpoints, submit_tx};
use serde_json::json;
use wiremock::matchers::{method, path};
use wiremock::{Mock, MockServer, Request, Respond, ResponseTemplate};

/// What the user means to pay the stranger's Seedelf, once.
const PAID: u64 = 2_000_000;

/// HAProxy's own 504 page: Koios's gateway took the request, and the instance
/// behind it didn't answer in time.
const GATEWAY_504: &str =
    "<html><body><h1>504 Gateway Time-out</h1>\nThe server didn't respond in time.\n</body></html>\n";

/// A node's refusal, as Koios passes on cardano-submit-api's answer.
const NODE_REFUSAL: &str = r#"{"contents":{"contents":{"contents":{"era":"ShelleyBasedEraConway","error":["ConwayUtxowFailure (UtxoFailure (ValueNotConservedUTxO ...))"],"kind":"ShelleyTxValidationError"},"tag":"TxValidationErrorInCardanoMode"},"tag":"TxCmdTxSubmitValidationError"},"tag":"TxSubmitFail"}"#;

/// `credential_utxos` as Koios pages it: `rows` at offset 0, then nothing.
struct Rows(Vec<UtxoResponse>);

impl Respond for Rows {
    fn respond(&self, request: &Request) -> ResponseTemplate {
        let first = request
            .url
            .query_pairs()
            .all(|(k, v)| k != "offset" || v == "0");
        ResponseTemplate::new(200).set_body_json(if first { json!(self.0) } else { json!([]) })
    }
}

fn pay_the_stranger() -> TransforArgs {
    TransforArgs {
        seedelfs: vec![SAMPLE_SEEDELF.to_string()],
        lovelaces: Some(vec![PAID]),
        assets: vec![],
        utxos: None,
    }
}

/// Every transaction the mock's `submittx` was handed, in order, as hex.
async fn submitted(server: &MockServer) -> Vec<String> {
    server
        .received_requests()
        .await
        .expect("request recording is on")
        .iter()
        .filter(|r| r.url.path() == "/api/v1/submittx")
        .map(|r| hex::encode(&r.body))
        .collect()
}

/// What a submit came back with: its own words alone (an error's outermost
/// message, or an outcome's debug form, should a fix return one as `Ok`), and
/// all of it, as the CLI prints an error (`Error: {err:#}`).
struct Said {
    own: String,
    full: String,
}

fn said<T: std::fmt::Debug, E: std::fmt::Display>(outcome: Result<T, E>) -> Said {
    match outcome {
        Ok(v) => Said {
            own: format!("{v:?}"),
            full: format!("Ok({v:?})"),
        },
        Err(e) => Said {
            own: format!("{e}"),
            full: format!("{e:#}"),
        },
    }
}

/// `submit_tx` once, with `answer` mounted for this call alone.
async fn submit_answered(server: &MockServer, answer: ResponseTemplate, cbor: &str) -> Said {
    let _only_now = Mock::given(method("POST"))
        .and(path("/api/v1/submittx"))
        .respond_with(answer)
        .mount_as_scoped(server)
        .await;
    said(submit_tx(cbor.to_string(), PREPROD).await)
}

#[tokio::test]
async fn a_submit_that_may_have_gone_through_does_not_read_as_not_sent() {
    let mut scenario = Scenario::start().await;
    let stranger = random_scalar();
    let their_seedelf = seedelf_utxo(stranger, 2, 1_500_000, SAMPLE_SEEDELF);
    scenario
        .mount_credential_utxos(vec![
            wallet_utxo(scenario.scalar, 1, 10_000_000, &[]),
            their_seedelf.clone(),
        ])
        .await;
    scenario.mount_evaluate(1).await;
    scenario.mount_collateral().await;
    let to_stranger = |tx: &DecodedTx| -> u64 {
        tx.outputs
            .iter()
            .filter(|o| {
                o.register
                    .as_ref()
                    .is_some_and(|r| r.is_owned(stranger).unwrap_or(false))
            })
            .map(|o| o.lovelace)
            .sum()
    };

    // ---- Part 1: what the user lives through (shown, not asserted) ----

    // Koios takes the transaction, and its gateway answers 504.
    let gateway = Mock::given(method("POST"))
        .and(path("/api/v1/submittx"))
        .respond_with(ResponseTemplate::new(504).set_body_raw(GATEWAY_504, "text/html"))
        .mount_as_scoped(&scenario.server)
        .await;
    let first = said(run(pay_the_stranger(), PREPROD, VARIANT).await);
    drop(gateway);
    println!("run 1 ends with: {}", first.full);
    let sent = submitted(&scenario.server).await;
    assert_eq!(sent.len(), 1, "Koios was handed run 1's transaction");
    let first_cbor = sent[0].clone();
    let first_tx = decode_tx(&first_cbor);
    let first_hash = hex::encode(
        *MultiEraTx::decode(&hex::decode(&first_cbor).expect("hex"))
            .expect("transaction")
            .hash(),
    );
    println!(
        "run 1's transaction {first_hash}, which Koios had, pays the stranger {} lovelace",
        to_stranger(&first_tx)
    );

    // It lands: the contract now holds its outputs, not the UTxO it spent.
    let mut landed = vec![their_seedelf.clone()];
    for (i, output) in first_tx.outputs.iter().enumerate() {
        let mut row = wallet_utxo(scenario.scalar, 0, output.lovelace, &[]);
        row.tx_hash = first_hash.clone();
        row.tx_index = i as u64;
        row.inline_datum = Some(register_inline_datum(
            output.register.as_ref().expect("a contract output's register"),
        ));
        landed.push(row);
    }
    Mock::given(method("POST"))
        .and(path("/api/v1/credential_utxos"))
        .respond_with(Rows(landed))
        .with_priority(1)
        .mount(&scenario.server)
        .await;

    // The user runs the same transfer again, and Koios answers this time.
    let accepted = Mock::given(method("POST"))
        .and(path("/api/v1/submittx"))
        .respond_with(ResponseTemplate::new(202).set_body_json(json!(tx_hash(2))))
        .mount_as_scoped(&scenario.server)
        .await;
    let second = run(pay_the_stranger(), PREPROD, VARIANT).await;
    drop(accepted);
    match second {
        Ok(()) => {
            let second_tx = decode_tx(&submitted(&scenario.server).await[1]);
            let spends_first = second_tx.inputs.iter().any(|(h, _)| *h == first_hash);
            println!(
                "run 2 succeeds: spends run 1's change: {spends_first}; pays the stranger {} lovelace more: {} in all for one {PAID} payment",
                to_stranger(&second_tx),
                to_stranger(&first_tx) + to_stranger(&second_tx)
            );
        }
        Err(e) => println!("run 2 fails: Error: {e:#}"),
    }

    // ---- Part 2: the assertion, on submit_tx itself ----

    let refused = submit_answered(
        &scenario.server,
        ResponseTemplate::new(400).set_body_raw(NODE_REFUSAL, "application/json"),
        &first_cbor,
    )
    .await;
    let before = submitted(&scenario.server).await.len();
    let gateway_504 = submit_answered(
        &scenario.server,
        ResponseTemplate::new(504).set_body_raw(GATEWAY_504, "text/html"),
        &first_cbor,
    )
    .await;
    // Koios would answer 202 at 90 s; the client gives up first (at 30 s).
    let timed_out = submit_answered(
        &scenario.server,
        ResponseTemplate::new(202)
            .set_body_json(json!(first_hash))
            .set_delay(Duration::from_secs(90)),
        &first_cbor,
    )
    .await;
    let had = submitted(&scenario.server).await.len() - before;
    assert_eq!(had, 2, "Koios had the transaction in both of those");

    // A connection that never opened: nothing left the machine.
    let closed = std::net::TcpListener::bind("127.0.0.1:0").expect("a free port");
    let port = closed.local_addr().expect("its address").port();
    drop(closed);
    override_endpoints(
        Some(format!("http://127.0.0.1:{port}")),
        Some(scenario.server.uri()),
    );
    let never_left = said(submit_tx(first_cbor.clone(), PREPROD).await);
    override_endpoints(Some(scenario.server.uri()), Some(scenario.server.uri()));

    for (case, s) in [
        ("not sent, the node's refusal (400)", &refused),
        ("not sent, a connection never opened", &never_left),
        ("may have gone, a gateway 504 after Koios had it", &gateway_504),
        ("may have gone, the 30 s timeout after Koios had it", &timed_out),
    ] {
        println!("{case}: {}", s.full);
    }

    let wrong: Vec<String> = [
        ("a gateway 504", &gateway_504),
        ("the client's 30 s timeout", &timed_out),
    ]
    .into_iter()
    .filter_map(|(case, s)| {
        let like = if s.own == refused.own {
            "the node's refusal"
        } else if s.own == never_left.own {
            "a connection that never opened"
        } else {
            return None;
        };
        Some(format!(
            "{case} after Koios had the transaction reads as not sent, in the words of {like}: \"{}\"",
            s.full
        ))
    })
    .collect();
    assert!(wrong.is_empty(), "{}", wrong.join("\n"));
}
```
