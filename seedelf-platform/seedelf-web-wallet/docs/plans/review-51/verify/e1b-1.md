# e1b#1: verification

From lane E1b, graded low by its finder.

## Trace: partly, low

The headline case holds, and a run confirms it. When giveme.my answers 429 (or a quick 5xx, or fails at once), bringAllBackNow's catch (lovejoin.ts:7407-7414) keeps the reason and moves to the next box. So each run builds every box's withdraw in WebAssembly and asks giveme.my once per box, and this repeats for three runs (BRING_FAILED_RUNS) before it stops. With 3 boxes the test saw 3, 3 and 3 requests (9 in all), where one a run is all the wallet can learn from.

It is narrower than written in three places:
(1) Koios's submit at 429. The Koios client sets the shared KOIOS_LIMIT cooldown on a 429 (koios.ts:1204-1207, 573-576): 10 s by default, 60 s at most. Every later Koios request waits it out (RateLimit.take, 554-557). So each next box's submit waits, a 2-minute run gets through about 11 boxes rather than 40, and the wallet does slow down as Koios asks. A giveme.my timeout (20 s) likewise caps a run at about 6 boxes.
(2) The per-box account_info read is chunk 43's recorded choice ("No cache of the balance: ... 9 reads for 9 boxes"). That part is known, not a finding.
(3) The finder's line "no test drives it with giveme.my busy" is wrong. Four tests do, but each has one or two boxes, so none counts requests per run.

Severity is low:
- Who reaches it: the user's own Settings or pool-page press, or retireOnce's run for boxes in retired pools.
- Nothing is lost.
- The cost is at most 3 × min(N, boxes buildable in 2 min) giveme.my requests and WASM builds while giveme.my says it is busy. That may keep giveme.my's per-IP limit tripped longer for the user's other private spends, depending on giveme.my's own limiter.
- The way out: it stops by itself with the reason and Try again, and Stop works throughout.

**Fix notes:**

In bringAllBackNow's catch (lovejoin.ts:7411-7413), end the run on an answer that belongs to the service rather than the box. Keep `why`, so three such runs still stop it with the reason (the stop rule the existing one-box test pins). The cases:
- a CollateralRefusedError with `busy` from a 429;
- a CollateralError that isn't a refusal (unreachable, timed out);
- a KoiosBusyError refused at submit with trouble "rate-limited". KOIOS_LIMIT's hold already paces those, but each one still throws away a giveme.my signature.

Tried in a copy: importing CollateralRefusedError (lovejoin.ts:152) and adding `if (e instanceof CollateralRefusedError && e.busy) break;` after `why = …` makes r51-e1b-1 pass. Four existing tests still pass with it: bring-all-back's two busy tests, bring-review-fixes' waits test and round2-retire's "giveme.my busy three runs".

One caution for 5xx: a 500 could be giveme.my failing on one transaction's body. The take order is fixed (classic pool's boxes first, then list order), so a break there would end every run at that same first box. The whole bring would then stop after three runs with nothing sent, where today the other boxes go. So end the run at once on a 429 and on unreachable or timeout. On a 5xx, end it only at the second busy answer in a row, or move the box that met it to the end of the next run.

Box-specific failures still pass the box over: NO_PRIVATE_PAYS, a refusal naming the box, a moved balance.

No other place multiplies the cost: withdrawDueNow sends one box a run (6936-6938).

Leave the per-box account_info alone unless the owner reopens chunk 43's choice.

No owner call needed: the fix adds no refusal, changes no privacy default and changes nothing a screen offers.

// Chunk 51, e1b#1 (the trace verifier's test). The wallet has three boxes in
// v2's 5 ₳ pool, the user presses Bring every box back now, and giveme.my is
// answering every request 429 (its limit for this IP). A 429 is the
// service's answer, not a box's: every other box's withdraw meets the same
// one. Today bringAllBackNow's catch (lovejoin.ts:7407-7414) keeps the reason
// and goes on to the next box, so each run builds every box's withdraw in
// WebAssembly and asks giveme.my once a box, three runs over
// (BRING_FAILED_RUNS) before it stops.
//
// What's right: a run ends at giveme.my's busy answer, as it ends at a lock
// or a withdraw that may have gone, so giveme.my is asked once a run while it
// says it's busy, and three such runs still stop it with the reason, as
// lovejoin-bring-all-back.test.ts's one-box test has it. Driven through the
// worker with the real WebAssembly.

import { describe, expect, it } from "vitest";

import { txInputs } from "../src/background/cbor";
import { Collateral } from "../src/background/collateral";
import type { KoiosUtxo } from "../src/background/koios";
import { BRING_FAILED_RUNS, LovejoinService } from "../src/background/lovejoin";
import { account, AGREES, PASSWORD, POOL } from "./chain-fixtures";
import { txIdOf } from "./fixtures/cbor";
import { busyFor, loadTestWasm, testBalances } from "./fakes";
import { ADA_POOL, ADA_ROWS, adaBox, madeByAdaMix, ownDatum, retiredAlready } from "./v2-pools";

/** Real withdraws are built and measured in WebAssembly: seconds each, more on CI. */
const SLOW = { timeout: 300_000 };

type T = ReturnType<typeof testBalances>;

/** Lovejoin reading v2's 5 ₳ pool beside the classic pool, giveme.my's witness stood in for. */
function pooled(t: T): LovejoinService {
  const wasm = loadTestWasm();
  return new LovejoinService({
    ...t.deps,
    wasm: {
      ...wasm,
      finishLovejoinWithdraw: (request: string) => {
        const { txCbor } = JSON.parse(request) as { txCbor: string };
        return JSON.stringify({ txCbor, txHash: txIdOf(Uint8Array.from(Buffer.from(txCbor, "hex"))) });
      },
    } as typeof wasm,
    collateral: () => new Collateral("https://www.giveme.my/preprod/collateral/", t.collateral.fetch),
    store: t.store,
    pools: async () => [ADA_POOL],
    random: () => 0.5,
  });
}

/** A box of the wallet's in v2's 5 ₳ pool, a mix there having made it five hours ago. */
async function fiveBox(t: T, tx: string): Promise<KoiosUtxo> {
  madeByAdaMix(t.koios, tx.repeat(32));
  return adaBox(tx, await ownDatum(t.wallet), t.clock.now, 5);
}

/** The boxes the withdraws giveme.my was asked about spend, `txhash#index`. */
const withdrawn = (t: T) => t.collateral.asked.flatMap((tx) => txInputs(Uint8Array.from(Buffer.from(tx, "hex"))));

type Sealed = { bringing?: { back: number; left?: number; why?: string; fails?: number; stopped?: true } };
const sealed = async (t: T) => (await t.store.get<Sealed>("lovejoin.preprod"))!;

describe("r51 e1b#1: Bring every box back now while giveme.my answers 429", SLOW, () => {
  it(`asks giveme.my once a run, not once a box, and still stops after ${BRING_FAILED_RUNS} runs that sent nothing`, async () => {
    const t = testBalances();
    await t.wallet.create(account(12).phrase, PASSWORD);
    t.koios.evaluation = AGREES;
    // Past 1.8.0's first run (retireOnce): the run below is the user's own press.
    await retiredAlready(t.store);
    const lj = pooled(t);
    const ours = await Promise.all(["f1", "f2", "f3"].map((tx) => fiveBox(t, tx)));
    t.koios.addedToAccounts.push(...POOL, ...ADA_ROWS, ...ours);
    await lj.status("preprod");
    await lj.bringAllBack("preprod");
    // giveme.my's limit for this IP: every request answered 429, whatever transaction it carries.
    t.collateral.answer = { status: 429, body: { detail: "Too Many Requests" } };
    const perRun: number[] = [];
    for (let run = 1; run <= BRING_FAILED_RUNS; run++) {
      const before = t.collateral.asked.length;
      // The alarm's run, a minute after the last.
      expect(await lj.withdrawDue("preprod")).toEqual([]);
      perRun.push(t.collateral.asked.length - before);
      expect((await sealed(t)).bringing).toMatchObject({ back: 0, left: 3, fails: run, why: expect.any(String) });
      await busyFor(t, 60_000);
    }
    expect((await sealed(t)).bringing?.stopped).toBe(true);
    expect(t.koios.submitted).toEqual([]);
    const boxes = withdrawn(t);
    expect(perRun, `giveme.my requests a run, ${boxes.length} in all over ${new Set(boxes).size} different boxes`).toEqual(
      Array.from({ length: BRING_FAILED_RUNS }, () => 1),
    );
  });
});
