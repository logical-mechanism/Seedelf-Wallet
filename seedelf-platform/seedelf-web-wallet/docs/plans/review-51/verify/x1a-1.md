## Trace: confirmed, low

The finding holds as described. I found no guard on the path. For base(the account's 0/0 payment key, a stranger's stake key), the worker gives exactly the answer it gives for the Receive address: {own: true, ownAccount: 0}. It throws away the carriesStakeKey = false it has just computed. So Send's and Make public's reviews read word for word as they do for the Receive address. Send says "This is your own public account: it comes back, less the fee." Make public says "This is your own public account: anyone can link it…". Neither says the stake part isn't the user's.

The connector judges the same shape the other way: cip30.rs own_address needs the account's stake key, and the sign window says "its staking rewards aren't yours". Its pinning test explains why: "its stake earns and votes for whoever holds the staking part".

What the reviews do say is true of the balance. The money comes back, Total leaving is the fee, and "after" is right, which fits the 1.7.2 lesson that "comes back" is a promise about the balance. What they leave out is that the stake and its rewards belong to the stranger's key while the money sits there.

My test fails on TREE because of this. A minimal fix in a throwaway copy (a worker flag plus one line in each review) makes the same, byte-identical test pass.

  /** Whether a useState's initial value is `want`: an empty object for `{}`, or the same value. */
  const matches = (initial: unknown, want: unknown) =>
    want && typeof want === "object" && !Object.keys(want).length
      ? !!initial && typeof initial === "object" && !Array.isArray(initial) && !Object.keys(initial).length

  const state = {
    seeds: [] as Array<{ after: unknown[]; value: unknown; used?: true }>,
    initials: [] as unknown[],
    /** What useState starts with: `initial`, or the seed whose run of initial values precedes this call. */
    seeded(initial: unknown): unknown {
      const before = state.initials;
      state.initials = [...before, initial];
      for (const seed of state.seeds) {
