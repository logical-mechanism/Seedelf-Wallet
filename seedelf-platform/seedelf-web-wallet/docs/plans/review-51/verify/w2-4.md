# w2#4: verification

From lane W2, graded low by its finder.

## Trace: confirmed, low

The finding holds as described. A Koios row for one of the account's UTxOs carries its reference script all the way into WebAssembly. There `KoiosRow` has no field for it, serde drops unknown fields silently, and `utxo_cbor` writes only the address, the value and the datum. So getUtxos hands every site the UTxO without the script it holds on chain.

I traced the whole path and found no guard on it:
- the reading (credential_utxos, trimmed);
- `available()`, which takes out only locks, the collateral and reserved inputs;
- `largestFirst` and `cover`;
- `encode()`, `cip30Utxos` and `utxo_cbor`.

Conway's minimum fee counts reference scripts on spent inputs, at 15 lovelace a byte in tiers. The project's own `build.rs:62-69` and `utxos.rs:348-353` say so, and launch review #12 recorded the node's FeeTooSmallUTxO refusal for the wallet's own builders, which now price it. So a site that prices its fee from the UTxO it was handed comes up short. Mesh, Lucid Evolution, Blaze and CSL all read the reference script from the UTxO they get from getUtxos. The node then refuses the signed transaction.

My test fails on TREE because of the bug and passes on a fixed copy.

Grade: low.
- **Who:** a stranger can reach it. Paying a 483-byte native script to the account's 0/0 costs about 3.1 ₳ of minimum ADA, which becomes the user's. The user's own deployed script reaches it too, and a 10 KB one holds about 45 ₳, so getUtxos lists it first.
- **Cost:** site transactions that pick that UTxO are refused at submit (phase 1). No fee or collateral is taken and no money moves.
- **Way out:** lock the UTxO in coin control, or move it with the wallet's own Send, which prices the script. Neither is easy to find: the public UTxOs screen flags only scripts the wallet can't measure (`coin-control.ts:324`), so nothing points at the cause.
- **Narrower cases:** a site that looks inputs up in its own chain index is unaffected. So is one whose fee estimate has slack above the script's fee.

**Evidence:**

Trace, from where the input enters to the outcome. All paths are relative to TREE, which matches tag web-wallet/1.9.1: `git diff web-wallet/1.9.1 HEAD` is empty for cip30.rs, dapp.ts, koios.ts and coin-control.ts.

1. **The row is read.** `account.ts:95-123` `readAccountUtxos` calls `koios.credentialUtxos` (`koios.ts:809-816`, `_extended: true`, every row `.map(trimmed)`). `trimmed` (`koios.ts:67-85`) keeps `reference_script: {hash,size,type,bytes}`, "never cut to nothing". `account.ts:120-123` keeps every row under one of the account's payment keys, whatever its staking part, so a stranger's output counts too.
2. **Nothing filters it out.** `dapp.ts:1671-1687` `available()` → `coins.account()` (`coin-control.ts:246-256`: `spendable = utxos.filter(p => p !== collateral && !locked.has(...))`), plus inflight outputs. For a session, `sessionCollateral` (`dapp.ts:2776`) takes out only the 5 ₳ collateral. Neither looks at reference scripts. The private side does (`balances.ts:474-476` `spendableOwned`: `!utxo.reference_script`).
3. **It is handed over.** `dapp.ts:603-604` getUtxos → `utxos()` (`dapp.ts:1711-1716`) → `paginate(this.encode(largestFirst(utxos)))`, or `cover()` (`dapp.ts:2914`) → `encode()` (`dapp.ts:1707-1709`) = `wasm.cip30Utxos(JSON.stringify(utxos.map(p => p.utxo)))`.
4. **WebAssembly drops the script.** `lib.rs:6809-6815` deserializes `Vec<cip30::KoiosRow>`. `cip30.rs:46-59` `KoiosRow { tx_hash, tx_index, address, value, datum_hash, inline_datum, asset_list }` has no `reference_script` and no `deny_unknown_fields`, so the field is dropped silently. `cip30.rs:284-286` says so itself: "A reference script on one of the account's own UTxOs isn't passed on." `cip30.rs:312-336` writes `map(3)` with keys 0/1/2, `array(3)` or `array(2)`, and never key 3.
5. **The same class, a second member.** `cip30.rs:971-997` `output_parts` ignores `o.script_ref`. `OwnOutput` (`cip30.rs:767-776`) has no script field, and `remember()` (`dapp.ts:2441-2462`) builds chained rows without one. So a chained output carrying a script is handed over bare as well.
6. **The ledger side.** `seedelf-core/src/build.rs:62-69`: Conway's fee "which the ledger adds for every script on a spent or reference input", 15 lovelace a byte in 25,600-byte tiers. `seedelf-core/src/utxos.rs:348-353`: never 0, "the fee would come out short, and the network would refuse the transaction". `docs/archive/plans/launch-review.md:232` (#12): "Public side: the fee leaves out Conway's reference-script fee for spent inputs, so the node refuses with FeeTooSmallUTxO."
7. **The outcome.** A site submits through `dapp.ts:2583-2586` `koios.submitTx`, and the refusal comes back to the site as an error. No money moves.

**Fix notes:**

Recommended fix (A), which the test pins. CIP-30's TransactionUnspentOutput is the output as it is on chain, and this fix changes no choice about which UTxOs a site gets. Give KoiosRow `#[serde(default)] reference_script: Option<{type, bytes}>`. In utxo_cbor, when one is present, write the map form with key 3 = `#6.24(bytes .cbor [kind, script])`:
- kind 0 for `timelock` or `multisig`, with the native script's CBOR embedded as is;
- 1, 2 or 3 for plutusV1, V2 or V3, with the script as a byte string. Check how Koios wraps a Plutus script's `bytes` against a real row first, such as a Lovejoin or Seedelf reference UTxO whose size core already prices.

A datum by hash then goes in as key 2 = [0, hash]. A row whose script can't be written (no bytes, not hex, an unknown type) should be left out of getUtxos and getBalance, never handed over without its script, following `measurable()`'s rule.

Fix the class:
- `output_parts` (cip30.rs:971) and `OwnOutput` (cip30.rs:767) should carry an output's script_ref, and `remember()` (dapp.ts:2441) should keep it, so chained outputs aren't handed over bare either.

Fix B (leave reference-script UTxOs out of getUtxos and getBalance in the worker, as the private side does) changes what a site is offered and hides UTxOs the ledger would let a site spend. It needs the owner, and the test would then belong in the worker (Vitest) rather than on utxo_cbor.

A note for the owner, beyond the finder's: a site that runs a Plutus V1 script and spends such an input is refused in phase 1 whatever its fee, because V1 can't represent a reference script on an input. With the script hidden, the site can't avoid that UTxO.

Also for the owner: the public UTxOs screen flags only scripts the wallet can't measure (coin-control.ts:324). A user hit by this has no hint which UTxO to lock.

//! Chunk 51, finding w2#4: `getUtxos` hands a site the account's UTxO without
//! the reference script it carries on chain. The worker passes WebAssembly the
//! Koios row with its `reference_script` kept (`trimmed`, koios.ts), but
//! `KoiosRow` has no field for it and `utxo_cbor` writes keys 0 to 2 only (or
//! the legacy array). A site that prices its fee from the UTxO it was handed
//! leaves out Conway's fee for a reference script on a spent input, and the
//! node refuses the signed transaction (`FeeTooSmallUTxO`). This asserts the
//! right behaviour, the output as the ledger holds it, so it fails while the
//! bug is there.

use pallas_codec::minicbor;
use pallas_codec::utils::CborWrap;
use pallas_crypto::hash::{Hash, Hasher};
use pallas_primitives::{Fragment, TransactionInput, conway};
use seedelf_core::build::reference_script_fee;
use seedelf_crypto::cardano::{CardanoAccount, Role};
use seedelf_koios::koios::ProtocolParameters;
use seedelf_wasm::cip30::{self, KoiosRow};

const PHRASE: &str =
    "abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about";
const TX_A: &str = "1111111111111111111111111111111111111111111111111111111111111111";

/// Mainnet's and preprod's fee parameters, 15 lovelace a byte of reference script.
fn params() -> ProtocolParameters {
    ProtocolParameters::from_koios(&serde_json::json!({
        "min_fee_a": 44, "min_fee_b": 155381, "coins_per_utxo_size": "4310",
        "key_deposit": "2000000", "price_mem": 0.0577, "price_step": 0.0000721,
        "min_fee_ref_script_cost_per_byte": 15,
        "cost_models": { "PlutusV3": [] },
    }))
    .unwrap()
}

#[test]
fn a_utxo_carrying_a_reference_script_is_handed_over_with_it() {
    // A stranger's native script: any of 15 keys, 483 bytes. Anyone can pay
    // the account's 0/0 an output carrying it, for its minimum ADA.
    let native = conway::NativeScript::ScriptAny(
        (1..=15u8)
            .map(|i| conway::NativeScript::ScriptPubkey(Hash::new([i; 28])))
            .collect(),
    );
    let script = native.encode_fragment().unwrap();
    assert_eq!(script.len(), 483);
    let address = CardanoAccount::from_phrase(PHRASE, 0)
        .unwrap()
        .base_address(true, Role::Receive, 0)
        .unwrap();

    // The row as the worker hands it to `cip30Utxos` (dapp.ts `encode`): Koios's
    // `credential_utxos` row, `trimmed`, its reference script kept.
    let row: KoiosRow = serde_json::from_value(serde_json::json!({
        "tx_hash": TX_A,
        "tx_index": 0,
        "address": address.to_bech32().unwrap(),
        "value": "5000000",
        "stake_address": null,
        "payment_cred": null,
        "block_height": 1,
        "inline_datum": null,
        "datum_hash": null,
        "asset_list": [],
        "reference_script": {
            "hash": hex::encode(Hasher::<224>::hash_tagged(&script, 0)),
            "size": script.len(),
            "type": "timelock",
            "bytes": hex::encode(&script),
        },
    }))
    .unwrap();

    let bytes = cip30::utxo_cbor(&row).unwrap();
    let mut d = minicbor::Decoder::new(&bytes);
    assert_eq!(d.array().unwrap(), Some(2));
    let input: TransactionInput = d.decode().unwrap();
    assert_eq!(hex::encode(input.transaction_id), TX_A);
    let output: conway::TransactionOutput = d.decode().unwrap();
    let script_ref = match output {
        conway::PseudoTransactionOutput::PostAlonzo(o) => o.script_ref,
        conway::PseudoTransactionOutput::Legacy(_) => None,
    };

    // What a site's fee leaves out when it can't see the script (Conway's
    // reference-script fee, the wallet's own reckoning of it).
    let short = reference_script_fee(&params(), script.len() as u64).unwrap();
    assert_eq!(short, 7_245);
    let Some(CborWrap(conway::PseudoScript::NativeScript(handed))) = script_ref else {
        panic!(
            "getUtxos hands the site {} without the reference script it holds on chain: \
             a fee priced from it is {short} lovelace short, and the node refuses the transaction",
            hex::encode(&bytes)
        );
    };
    assert_eq!(handed.encode_fragment().unwrap(), script);
}
