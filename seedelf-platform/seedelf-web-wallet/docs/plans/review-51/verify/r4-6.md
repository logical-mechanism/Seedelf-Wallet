# r4#6: verification

From lane R4, graded low by its finder.

## Trace: confirmed, low

The finding holds as described. `create`, `fund` and `util extract` serve the unsigned transaction from 127.0.0.1:44203. No route checks Host, Origin or method. Neither warp 0.3.7 nor hyper 0.14.32 checks the authority unless a route opts in with `warp::host::exact`, and this file doesn't. So a request whose Host is a rebinding site's own name (`rebind.example:44203`) gets the full page, with the transaction in its injected JSON. I couldn't find a missed guard or a caller that avoids it, and no test covers it: every CLI test arms the capture seam, so the server never runs under test. My test drives the real `fund` command into the real server and fails on TREE because of this. The same test passes against a copy with a Host filter.

Grade: low, as the finder said.
- **Who:** a site the user has open on the same machine while the CLI waits for Ctrl-C. It also needs a browser that lets a public page reach loopback after a rebinding, a DNS resolver that passes a 127.0.0.1 answer, and a plain-http frame, because the CLI's server speaks HTTP only.
- **Cost:** privacy only. The site learns, tied to its visitor, the paying address, its UTxOs and collateral, the amount, and for `create` the new Seedelf's name and register. All of that goes public at submit. The site gets it earlier, and also if the user never signs. No key, no signature and no funds are reachable: the server holds no key and takes no input.
- **Way out:** close other sites while the CLI serves, or use a browser that blocks local-network access.

It isn't known: nothing in the backlog, the archived reviews, chunk 46/49, SECURITY.md or the READMEs covers it. It's in the CLI's bounty scope (0.7.0), but it can't earn a bounty, since SECURITY.md pays only for a loss of funds.

//! Chunk 51, finding r4#6: the CLI's signing server answers any Host header,
//! so a DNS-rebinding page can read the unsigned transaction.
//!
//! Once a site has rebound its own name to 127.0.0.1, the browser sends the
//! site's requests for http://<that name>:44203/ to the CLI's server, with
//! `Host: <that name>:44203`, and the site reads the answers as its own
//! origin's. The right behaviour: the server answers only its own authority,
//! the one it prints (127.0.0.1:44203, or localhost:44203), and a request for
//! any other Host gets neither a 2xx nor the transaction.
//!
//! This drives the real `fund` command against tests/cli's mock Koios (its
//! harness is included here unchanged) with the capture seam left unarmed, so
//! `seedelf_cli::web_server::run_web_server` really serves on 127.0.0.1:44203.
//! The request with the server's own Host is the control: it must get the
//! page and this run's fund transaction, before a fix and after it.

#[path = "cli/harness.rs"]
mod harness;

use std::time::Duration;

use harness::*;
use seedelf_cli::commands::fund::{FundArgs, run};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::TcpStream;
use tokio::time::{Instant, sleep, timeout};

/// Where the CLI serves its signing page, as `display::webserver_address` prints it.
const SERVER: &str = "127.0.0.1:44203";
/// The Host a browser sends for a site whose name now resolves to 127.0.0.1.
const REBOUND_HOST: &str = "rebind.example:44203";

/// One `GET /` to the signing server with the given Host header: the status
/// code and the whole raw response, head and body.
async fn get_page(host: &str) -> std::io::Result<(u16, String)> {
    let mut stream = TcpStream::connect(SERVER).await?;
    let request =
        format!("GET / HTTP/1.1\r\nHost: {host}\r\nAccept: text/html\r\nConnection: close\r\n\r\n");
    stream.write_all(request.as_bytes()).await?;
    let mut raw = Vec::new();
    timeout(Duration::from_secs(10), stream.read_to_end(&mut raw))
        .await
        .map_err(|_| std::io::Error::new(std::io::ErrorKind::TimedOut, "no answer in 10 s"))??;
    let text = String::from_utf8_lossy(&raw).into_owned();
    let status = text
        .split_whitespace()
        .nth(1)
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    Ok((status, text))
}

/// The transaction hex the page carries in its `injected-data` block.
fn injected_tx(page: &str) -> Option<String> {
    const OPEN: &str = r#"{ "message": ""#;
    let start = page.find(OPEN)? + OPEN.len();
    let len = page[start..].find('"')?;
    Some(page[start..start + len].to_string())
}

#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn signing_server_gives_the_transaction_only_to_its_own_host() {
    // The port is fixed: with anything else listening there, this test
    // couldn't tell the CLI's server from it.
    drop(std::net::TcpListener::bind(SERVER).unwrap_or_else(|err| {
        panic!("{SERVER} is in use ({err}): stop whatever listens there and run again")
    }));

    let mut scenario = Scenario::start().await;
    scenario
        .mount_credential_utxos(vec![seedelf_utxo(
            scenario.scalar,
            1,
            1_500_000,
            SAMPLE_SEEDELF,
        )])
        .await;
    scenario
        .mount_address_utxos(vec![address_utxo(
            &external_address_bech32(),
            2,
            10_000_000,
            &[],
        )])
        .await;
    // The capture seam stays unarmed: fund ends in the real signing server,
    // which serves until Ctrl-C. Dropping the future below stops it.

    let fund = run(
        FundArgs {
            address: external_address_bech32(),
            seedelf: SAMPLE_SEEDELF.to_string(),
            lovelace: Some(3_000_000),
            assets: vec![],
        },
        PREPROD,
        VARIANT,
    );

    let probe = async {
        let deadline = Instant::now() + Duration::from_secs(60);
        let own = loop {
            match get_page(SERVER).await {
                Ok(answer) => break answer,
                Err(err) if Instant::now() >= deadline => {
                    panic!("the signing server never answered on {SERVER}: {err}")
                }
                Err(_) => sleep(Duration::from_millis(50)).await,
            }
        };
        // A connection the server drops or resets hands the site nothing.
        let rebound = get_page(REBOUND_HOST).await.unwrap_or((0, String::new()));
        (own, rebound)
    };

    let ((own_status, own_page), (status, page)) = tokio::select! {
        ended = fund => panic!("fund stopped before its page was read: {ended:?}"),
        answers = probe => answers,
    };

    // The control: the page the CLI prints works, with this run's transaction.
    assert_eq!(own_status, 200, "the signing page at {SERVER} must load:\n{own_page}");
    let tx_hex = injected_tx(&own_page).expect("the signing page carries the transaction");
    let tx = decode_tx(&tx_hex);
    let funded: Vec<u64> = tx
        .outputs_to(&wallet_address())
        .iter()
        .map(|o| o.lovelace)
        .collect();
    assert_eq!(funded, vec![3_000_000], "the page carries this run's fund transaction");

    // The finding: a request for any other Host gets neither a 2xx nor the
    // transaction.
    let leaked = page.contains(&tx_hex);
    let what = if leaked {
        let outputs: Vec<String> = tx
            .outputs
            .iter()
            .map(|o| {
                format!(
                    "{} lovelace to {}{}",
                    o.lovelace,
                    o.address.to_bech32().unwrap_or_default(),
                    if o.has_datum { " (with a datum)" } else { "" }
                )
            })
            .collect();
        format!(
            "and the unsigned transaction ({} hex chars): it spends {:?}, pays {}",
            tx_hex.len(),
            tx.inputs,
            outputs.join(", and ")
        )
    } else {
        "and no transaction".to_string()
    };
    assert!(
        !(200..300).contains(&status) && !leaked,
        "a request with Host: {REBOUND_HOST}, a DNS-rebinding site's own origin, got status {status} {what}"
    );
}
