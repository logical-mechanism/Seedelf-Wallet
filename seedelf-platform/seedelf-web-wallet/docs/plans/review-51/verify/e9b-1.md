# e9b#1: verification

From lane E9b, graded low by its finder.

## Trace: confirmed, low

The path goes through and I found no guard that stops it. foldName (format.ts:79-83) lower-cases a name before it maps lookalike letters. LOOKS_LIKE (format.ts:55-61) maps the small Greek letters by the Latin letter each one draws: ν→v, μ→u, η→n, υ→u. So the capitals Ν Μ Η Υ, which draw N M H Y, fold to the wrong letters. Cherokee and Lisu letters aren't mapped at all. tokenText (tokens.ts:105-118) is the one place every view asks how to name a token, and src/ has no other script or confusable check. The test shows each consequence on TREE:
- the skeletons are wrong;
- posesAs stays undefined for tUSDΜ and ΜΙΝ (preprod) and for SΝΕΚ, USDΜ and ΗOSKY (mainnet);
- Cherokee ᎪᎠᎪ and Lisu ꓮꓓꓮ keep their own name instead of being marked as posing as ADA;
- Home's row has the fingerprint as its second line, with no warning;
- a site's signing prompt reads "Gets 10,000 tUSDΜ Not on the wallet's list, asset1…" and its warn Callout `dapp-lookalike` never appears;
- NUNA and ΝUΝΑ aren't counted as sharing a ticker.

The finder didn't name the callout, and it is the largest visible loss. With a candidate fix in a copy, the same test passes 9 of 9.

Two of the finder's words go further than the facts:
- "look exactly like Latin ones in every font": the wallet's Inter ships Latin and Latin-ext only (styles.css:5-26), so Greek renders in the system font. That is the same as the Cyrillic spellings the wallet already catches, so the spoof is as convincing as one that's guarded today.
- Cherokee and Lisu need a system font for those scripts; without one they render as boxes.

Severity is low, as the finder graded it. A stranger reaches it with one mint and a send, and a site can reach it through the tokens its transaction shows. But the first layer holds everywhere: no logo, the fingerprint, and "not on the wallet's list" in every text view. No figure is wrong and nothing is signed other than what's shown. Harm needs the user to be fooled despite those marks.

**Fix notes:**

Fix the class at its root in foldName (format.ts:79-83). Map capitals and caseless letters that draw a Latin letter before lower-casing, then apply the existing lowercase table.

The candidate I checked in a copy:
```ts
const CAPITALS_LOOK_LIKE = { Α:"a", Β:"b", Ε:"e", Ζ:"z", Η:"h", Ι:"l", Κ:"k", Μ:"m", Ν:"n", Ο:"o", Ρ:"p", Τ:"t", Υ:"y", Χ:"x", Ꭺ:"a", Ꭰ:"d", ꓮ:"a", ꓓ:"d" };
const stripped = name.normalize("NFKD").replace(/[\p{M}\p{Cf}\p{Default_Ignorable_Code_Point}]/gu, "");
return [...[...stripped].map((c) => CAPITALS_LOOK_LIKE[c] ?? c).join("").toLowerCase()].map((c) => LOOKS_LIKE[c] ?? c).join("");
```
With it, r51-e9b-1 passes 9 of 9.
