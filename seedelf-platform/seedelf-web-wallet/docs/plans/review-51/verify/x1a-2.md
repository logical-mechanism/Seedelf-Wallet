# x1a#2: verification

From lane X1a, graded low by its finder.

## Trace: confirmed, low

I couldn't refute it. A site's output to the contract is classed "register" on its datum's shape and on is_payable alone (cip30.rs:1386-1387). is_payable (build.rs:3107) checks only that the points are torsion-free and not the identity, so any live Seedelf's register as found passes. That class alone brings up the callout "It pays a Seedelf. Nothing on chain says whose, but it comes from your public account in the open." (DappApprovals.tsx:1190-1192). privacy.md:336 makes the same promise ("whose owner stays hidden").

Nothing on the way compares the register with anything already on chain:
- the worker's readTx (dapp.ts:2030) and ties() (dapp.ts:2265) look at Cardano keys only;
- WebAssembly is never given the contract;
- Transaction details only marks a register payable, or the user's own (decode.rs:1221, tx-view.ts:280).

The worker does have what a check would need, with no request: contract-scan.ts:83 and :400 keep every Seedelf's register in the kept view. The test shows it holds both Seedelfs' datums byte for byte.

On chain, the output's datum is the datum of the UTxO holding that Seedelf's token, so anyone can see which Seedelf it pays. For the user's own Seedelf, the public account, the Seedelf and the new private UTxO end up tied together, and so does whatever is later spent beside that UTxO.

The test fails on TREE for exactly this, for someone else's Seedelf and for the user's own, while every precondition holds.

Severity is low:
- Who: any connected site (the session window has the same words).
- Cost: no money. A privacy line is false, but only in an edge case: the site has to skip re-randomizing.
- Way out: the user can decline. Nothing in the window or Transaction details flags the shape.
- A refusal is ruled out by the owner's rule, since the ledger accepts the transaction.

A comparison with keptContractView (every Seedelf's Locator.register plus the wallet's owned rows, no request) catches only d = 1 copies of a Seedelf's register or of the wallet's own UTxOs. It can't catch:
- a small d ≠ 1, the README's literal brute-force case: (g^2, u^2) is found by trying small d against every Seedelf register;
- a copy of a stranger's UTxO that holds no token, since the view doesn't keep those.

And the site always knows its own d. So "say only what's checked" points to softening the line for every register a site writes, along the lines of "It pays a Seedelf under a register the site chose: the wallet can't check it hides whose". The kept-view match could add a short .warn./.privacy. line where it hits ("this register is already on chain: anyone can see whose Seedelf it pays"). New keys need the .warn./.privacy. names for the critical-set guard.

This is worth doing in the same change as w2#2 and d1#3 at cip30.rs:1386. The new test (tests/r51-x1a-2.test.ts) passes under either fix. // Chunk 51, finding x1a#2 (its trace verifier's test). A site's transaction pays 25 ₳ of the public account's into
// Seedelf Wallet's contract under a Seedelf's register written as found: the inline datum of the UTxO holding its
// token, byte for byte, never re-randomized (d = 1, the root README's "bad d value"). WebAssembly reads it as a
// payable register (cip30.rs:1386, `seedelf: "register"`), and the window says "It pays a Seedelf. Nothing on chain
// says whose, but it comes from your public account in the open." (privacy.md:336: "whose owner stays hidden"). On
// chain the output's datum is the Seedelf's own, so anyone can see whose Seedelf it pays. The worker holds every
// Seedelf's register in the kept contract view, asking nobody, and nothing compares them. This asserts the right
// behaviour, so it fails while the bug is there: the window never says nothing on chain names a Seedelf whose
// register is already on chain beside its token.
import { createElement } from "react";
import { renderToStaticMarkup } from "react-dom/server";
import { describe, expect, it } from "vitest";

import { CONTRACT_V1 } from "../src/background/balances";
import { keptContractView } from "../src/background/contract-scan";
import type { DappSession } from "../src/background/dapp";
import type { KoiosUtxo } from "../src/background/koios";
import type { DappApproval } from "../src/shared/rpc";
import { SignTx } from "../src/ui/screens/DappApprovals";
import { koiosPreprod, ownedUtxos, testBalances, vectors } from "./fakes";

const PASSWORD = "correct horse battery";
const ACCOUNT = vectors("cardano_account.json").find((v) => v.account === 0 && v.phrase.split(" ").length === 12)!;
/** The account's receive address 0/0. */
const OWN = ACCOUNT.preprod.receive_0 as string;
/** A pure 100 ₳ UTxO of the account's at 0/0, which the site's transaction spends. */
const FUNDS = { tx_hash: "c1".repeat(32), tx_index: 0, lovelace: 100_000_000n };
const PAID = 25_000_000n;
const FEE = 170_000n;

async function until(check: () => boolean) {
  for (let i = 0; i < 200 && !check(); i++) await new Promise((r) => setTimeout(r, 0));
  expect(check()).toBe(true);
}

/** A CBOR byte string of 24 to 255 bytes. */
const bytesOf = (hex: string) => `58${(hex.length / 2).toString(16).padStart(2, "0")}${hex}`;
const coin = (n: bigint) => (n < 0x100000000n ? `1a${n.toString(16).padStart(8, "0")}` : `1b${n.toString(16).padStart(16, "0")}`);

/** Seedelf Wallet's contract on preprod, as seedelf-core's `wallet_contract` builds it: its script hash, no staking part. */
const CONTRACT = `70${CONTRACT_V1.walletContractHash}`;

/**
 * A site's transaction: it spends FUNDS, pays 25 ₳ into the contract under the inline datum `datum` (CBOR, hex), and
 * the rest less its 0.17 ₳ fee back to `change` (CIP-30 hex). The wallet only reads it.
 */
function paysContract(datum: string, change: string) {
  const inputs = `81825820${FUNDS.tx_hash}00`;
  const toContract = `a300${bytesOf(CONTRACT)}01${coin(PAID)}028201d818${bytesOf(datum)}`;
  const back = `82${bytesOf(change)}${coin(FUNDS.lovelace - PAID - FEE)}`;
  return `84a300${inputs}0182${toContract}${back}02${coin(FEE)}a0f5f6`;
}

/** The Seedelf token a contract row holds, if it holds one. */
const seedelfOf = (u: KoiosUtxo) => (u.asset_list ?? []).find((a) => a.policy_id === CONTRACT_V1.seedelfPolicyId)?.asset_name;

describe("a site's payment into a Seedelf under its register as found (chunk 51, x1a#2)", () => {
  it("is never shown as one whose Seedelf nothing on chain names", { timeout: 60_000 }, async () => {
    const t = testBalances();
    await t.wallet.create(ACCOUNT.phrase as string, PASSWORD);
    await t.preferences.set({ dappConnector: true, spendRewards: false });
    const template = Object.values(koiosPreprod.accounts)
      .flatMap((a) => a.account_utxos)
      .find((u) => u.address === OWN)!;
    t.koios.addedToAccounts.push({
      ...template,
      tx_hash: FUNDS.tx_hash,
      tx_index: FUNDS.tx_index,
      value: FUNDS.lovelace.toString(),
      asset_list: [],
      block_height: 1,
    });
    const s: DappSession = { id: "r51-x1a-2", origin: "https://pay.example", title: "Pay a Seedelf" };
    const enabling = t.dapp.call(s, "enable", []);
    await until(() => t.dapp.approvals().length === 1);
    await t.dapp.answer(t.dapp.approvals()[0]!.id, true);
    expect(await enabling).toBe(true);
    // A balance reading, as Home makes after an unlock: it reads the contract and keeps where each Seedelf is.
    await t.balances.get("preprod");
    expect((await t.coins.lists("preprod")).cardano.some((u) => u.txHash === FUNDS.tx_hash)).toBe(true);
    const view = await keptContractView(t.session, "preprod");
    const { wasm } = t.deps;

    // Someone's Seedelf (a real preprod one) and the wallet's own: the datum of the UTxO holding each token, as found.
    const theirs = koiosPreprod.contract_utxos.find((u) => seedelfOf(u) && u.inline_datum)!;
    const ours = ownedUtxos.find((u) => seedelfOf(u) && u.inline_datum)!;
    for (const [who, row] of [
      ["someone's", theirs],
      ["the wallet's own", ours],
    ] as const) {
      const name = seedelfOf(row)!;
      const asFound = row.inline_datum!.bytes;
      // The kept view holds that very register beside that Seedelf's token: comparing needs no request.
      expect(view?.seedelfs[name]?.inline_datum?.bytes, who).toBe(asFound);

      const signing = t.dapp.call(s, "signTx", [paysContract(asFound, wasm.cip30Address(OWN)), false]);
      await until(() => t.dapp.approvals().length === 1);
      const approval = t.dapp.approvals()[0]! as Extract<DappApproval, { kind: "sign-tx" }>;
      await t.dapp.answer(approval.id, false);
      await expect(signing).rejects.toMatchObject({ failure: { info: "The user declined." } });
      const { summary, ties, staked, certified } = approval;
      // The window was opened for it: 25 ₳ into a contract under an inline datum, the change back to 0/0, its fee.
      expect(summary.paid.map((p) => [p.lovelace, p.datum, p.script]), who).toEqual([["25000000", "inline", true]]);
      expect(summary.ownOutputs.map((o) => o.lovelace), who).toEqual(["74830000"]);
      expect(summary.netLovelace, who).toBe("-25170000");
      expect(summary.signs, who).toEqual(["0/0"]);
      const page = renderToStaticMarkup(
        createElement(SignTx, { summary, partial: false, session: false, collateralSpent: false, ties, staked, certified }),
      )
        .replace(/<[^>]+>/g, " ")
        .replace(/&#x27;/g, "'")
        .replace(/\s+/g, " ");
      console.log(`[r51 x1a#2] ${who} Seedelf ${name.slice(0, 16)}…: paid[0].seedelf = ${summary.paid[0]!.seedelf}`);
      // On chain this output's datum is the one beside the Seedelf's token, so anyone can see whose Seedelf it pays.
      expect.soft(page, `${who} Seedelf, paid under its register as found`).not.toContain("Nothing on chain says whose");
    }
  });
});
