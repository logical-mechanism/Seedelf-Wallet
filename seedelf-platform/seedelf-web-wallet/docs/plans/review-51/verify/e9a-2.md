## Trace: confirmed, low

The trace holds from start to finish. The decoder's TxAsset has no decimals, tx-view.ts adds none, and the `tx-detail` handler passes its answer straight to the screen. So TxDetail's `amount()` gets `tokenDecimals(network, t)` = the wallet's list's decimals, then `t.decimals` (always undefined here), then 0. Any token off the wallet's list (32 mainnet, 2 preprod) therefore shows in raw units.

Home and the reviews scale the same token by Koios's or the data layer's decimals. Home's TokenAmount.decimals comes from each row's `_extended` asset_list. The reviews (CardanoSend, Withdraw, Transfer, MoveIn) use `tokenQuantity(network, {...held, ...tk})`, and the summary's tokens carry no decimals, so the held token's decimals win.

No guard, earlier check or test covers this. token-text.test.ts pins the 0 fallback itself, and tx-view-screen.test.ts never checks a token amount.

My test runs the real worker over the real WebAssembly. The account holds 100 FOO (6 decimals, from Koios) and the user sends 1.5 FOO publicly:
- Home reads 100.
- The review row computes "1.5".
- Transaction details under that review reads "1,500,000 FOO" for the recipient and "98,500,000 FOO" for the change.

In a copy, I made tx-view.ts attach the kept reading's decimals, as activity.ts withDecimals does for Activity, and the same test passes.

Grade: low.
- Who: the user, by an ordinary send of a held token that's off the list but has registry decimals. The data layer knows 1,176 such tokens, the list only 32.
- Cost: no money moves wrongly. The transaction pays exactly what the review shows. The view always overstates (raw is never less than scaled), so it never understates what leaves. The cost is a contradiction under the review, which the blind test recorded as hurting trust.
- Way out: the review, Home and Activity are right.

One nuance in the sign window (`site`): its own rows are raw too (DappToken has no decimals, DappApprovals.tsx:1035). There the view agrees with the window and contradicts only Home. A site gains nothing from this, because a token the user doesn't hold already shows raw by design, with the "not on the wallet's list" mark.

// Chunk 51, finding e9a#2: Transaction details show a token that isn't on the
// wallet's list in raw units, while Home and the review above them scale it by
// the decimals Koios gave the balance reading. Real worker, real WebAssembly,
// over the fake Koios: the account holds 100 FOO (6 decimals, Koios's), sends
// 1.5 FOO publicly, and opens Transaction details under that review.
import { createElement, type ReactElement } from "react";
import { renderToStaticMarkup } from "react-dom/server";
import { describe, expect, it } from "vitest";

import { txView } from "../src/background/tx-view";
import { assetFingerprint } from "../src/shared/fingerprint";
import { TxDetailBody } from "../src/ui/components/TxDetail";
import { NetworkContext } from "../src/ui/network";
import { tokenQuantity, viewToken } from "../src/ui/tokens";
import { koiosPreprod, testBalances, vectors } from "./fakes";

const PASSWORD = "correct horse battery";
const account = (words: number) =>
  vectors("cardano_account.json").find((v) => v.account === 0 && v.phrase.split(" ").length === words)!;
const OWN = account(12).preprod.receive_0 as string;
const THEIRS = account(15).preprod.receive_0 as string;

/** A token off the wallet's list (2 preprod, 32 mainnet), whose decimals Koios knows from the token registry: 6. */
const FOO = { policyId: "f0".repeat(28), assetName: Buffer.from("FOO").toString("hex") };
const key = (x: { policyId: string; assetName: string }) => `${x.policyId}.${x.assetName}`;

/** A page's text, as a person reads it (tx-view-screen.test.ts's). */
function text(element: ReactElement): string {
  return renderToStaticMarkup(createElement(NetworkContext.Provider, { value: "preprod" }, element))
    .replace(/<[^>]*>/g, " ")
    .replace(/&#x27;/g, "'")
    .replace(/&quot;/g, '"')
    .replace(/&amp;/g, "&")
    .replace(/\s+/g, " ")
    .trim();
}

describe("r51 e9a#2: Transaction details and the review above them agree on a token's units", () => {
  it("shows an unlisted token with Koios's decimals as Home and the review do", async () => {
    const t = testBalances();
    await t.wallet.create(account(12).phrase, PASSWORD);
    const template = Object.values(koiosPreprod.accounts)
      .flatMap((a) => a.account_utxos)
      .find((u) => u.address === OWN)!;
    t.koios.addedToAccounts.push({
      ...template,
      tx_hash: "f1".repeat(32),
      tx_index: 0,
      value: "5000000",
      asset_list: [
        { policy_id: FOO.policyId, asset_name: FOO.assetName, quantity: "100000000", decimals: 6, fingerprint: assetFingerprint(FOO) },
      ],
      block_height: 1,
    });

    // Home: the reading carries Koios's decimals, and the token list shows 100 FOO (Tokens.tsx, viewToken).
    const reading = await t.balances.get("preprod");
    const held = reading.cardano.tokens.find((x) => key(x) === key(FOO))!;
    expect(held.decimals).toBe(6);
    expect(viewToken("preprod", held).amount).toBe("100");

    // Send publicly, 1.5 FOO: the review's row reads "1.5 FOO", as CardanoSend.tsx:183-191 builds it.
    const summary = await t.send.build("preprod", [{ to: THEIRS, lovelace: "0", tokens: [{ ...FOO, quantity: "1500000" }] }]);
    const tk = summary.payments[0]!.tokens.find((x) => key(x) === key(FOO))!;
    expect(tokenQuantity("preprod", { ...held, ...tk })).toBe("1.5");

    // Transaction details under that review: what the worker answers "tx-detail" with (handlers.ts), as the modal shows it.
    const { detail } = await txView({ wasm: t.deps.wasm, wallet: t.wallet, session: t.session }, "preprod", summary.txHash);
    const paid = detail.outputs.find((o) => o.address.bech32 === THEIRS)!;
    expect(paid.assets.find((a) => key(a) === key(FOO))?.quantity).toBe("1500000");
    const page = text(createElement(TxDetailBody, { detail, network: "preprod", testId: "tx" }));

    // The same 1.5 FOO the review shows, and the change's 98.5 FOO, not their raw units.
    expect(page).toContain("1.5 FOO");
    expect(page).toContain("98.5 FOO");
    expect(page).not.toContain("1,500,000 FOO");
  });
});
