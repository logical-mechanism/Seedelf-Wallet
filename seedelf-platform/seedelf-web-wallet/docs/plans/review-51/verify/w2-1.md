# w2#1: verification

From lane W2, graded low by its finder.

## Trace: confirmed, low

The finding holds. I traced it end to end in TREE, and a test shows it failing today.

- **The count.** `stake_hash` (cip30.rs:1068-1073) returns None for a script's credential. So every stake certificate under a script falls to `None => others_sign += 1` (cip30.rs:1610), and `complete` is false (1841-1842).
- **The dead arm.** The `Some(_) => {}` arm, whose comment names "a script's stake credential" (1607-1608), can never receive one.
- **The refusal.** Without partialSign, `sign_tx` refuses at 1958-1962. The worker refuses earlier, at dapp.ts:2087-2088, before the window opens. The site's flag counts as true only when it is literally `true` (dapp.ts:616 `args[1] === true`, page.ts:65 `partialSign ?? false`). Mesh 1.8.14's BrowserWallet defaults it to false.
- **The ledger asks no key.** Conway asks a certificate for `credKeyHashWitness cred`, which is Nothing for a script. Shelley's cert 0 (`ConwayRegCert _ SNothing`) needs no witness of any kind. seedelf-core agrees (staking.rs:514-524 "a script's credential, which no key signs for"), and its own Lovejoin launch registers mix_logic with cert 0 and no witness.
- **The connector disagrees with itself.** It counts no one for a script input (1219), a script's zero withdrawal (1656-1657) or a script DRep's certificate (1589). The test's two controls show exactly that.
- **No guard found.** `stakeDeposit` acts only on cert 1, `ties` keeps `complete`, sessions refuse every certificate anyway (sessions.ts:6867), and no test pins `complete` for a script certificate.

One nuance: a native script can itself name other keys. The connector can't tell that from the body, and it treats scripts as keyless everywhere else, so the class claim stands; cert 0 holds without that nuance.

**Severity: low.** A site's valid transaction with a script-credential stake certificate is refused, with false words ("needs signatures the wallet can't give"). This is an edge case: registering a withdraw-zero validator's credential, or delegating a script-staked credential. With partialSign true it signs, but the info callout falsely says "Others sign too before it's sent." No money moves. The only way out is the site's, by passing partialSign true.

**Fix notes:**

**The fix.** In cip30.rs's certificate loop, decide by the credential's kind:

1. Add `None if matches!(cred, Some(StakeCredential::ScriptHash(_))) => {}` before `None => others_sign += 1` (cip30.rs:1610). A script's credential then counts no signer, as the same function already does for script inputs (1219), script withdrawals (1656-1657) and script DRep certificates (1589).
2. Correct the comment at 1607. It puts "a script's stake credential" under `Some(_)`, which a script can never reach because stake_hash returns None for it.

I checked this fix in a copy: the new test passes and all 73 cip30_test tests still pass.

**Others in the class:**
- AuthCommitteeHot and ResignCommitteeCold enter the match with `cred = None` (1548-1550), so a script cold credential also counts as another signer. The ledger asks only the script there. Carrying the cold credential in, and counting one only for a key cold credential, closes it.
- Pool registration and retirement rightly count one: the operator signs.

**Caveat.** A native script can name other keys. The connector can't tell from the body, and treats scripts as keyless everywhere else, so missing witnesses would only fail at submit, with no money moving.

**Also worth doing:** pin `complete` for a lone script certificate in cip30_test.rs, since a_stake_certificate_says_whose_stake_key_it_names doesn't.

**Owner.** No refusal is added and no privacy default changes, so this doesn't need the owner. The certificate line's wording for a script ("A certificate for a stake key that isn't yours.", dappUi.cert.warn.otherStakeKey) was left as is in 1.7.2 and isn't part of this.

//! Chunk 51, finding w2#1: a certificate under a script's stake credential is
//! counted as a signature someone else must give (`others_sign`), so the
//! transaction is never `complete`. Without partialSign it is refused before
//! the window opens; with it the window says others sign too.
//!
//! No key signs for a script's credential. Conway's ledger asks a certificate
//! for `credKeyHashWitness cred`, which is Nothing for a script, and Shelley's
//! registration (certificate 0, `ConwayRegCert _ SNothing`) needs no witness
//! of any kind. seedelf-core says the same (`staking.rs` `is_scripts`: "a
//! script's credential, which no key signs for"), and the connector already
//! counts no one for a script's zero withdrawal or a script DRep's certificate:
//! the two controls below, which pass today.
//!
//! The transaction: the account's 5 ₳ at 0/0 in, 2.8 ₳ back to 0/0, a 0.2 ₳
//! fee, and one certificate under a script's credential, sent without
//! partialSign.

use pallas_addresses::Address;
use pallas_codec::utils::{Bytes, NonEmptyKeyValuePairs, NonEmptySet, Nullable, Set};
use pallas_crypto::hash::Hash;
use pallas_primitives::{Fragment, StakeCredential, TransactionInput, conway};
use seedelf_crypto::cardano::{CardanoAccount, Role};
use seedelf_wasm::cip30::{self, KeyPath, KoiosRow, TxRequest};

const PHRASE: &str =
    "abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about";
const TX_A: &str = "1111111111111111111111111111111111111111111111111111111111111111";
const SCRIPT: [u8; 28] = [6; 28];

fn account() -> CardanoAccount {
    CardanoAccount::from_phrase(PHRASE, 0).unwrap()
}

fn ours() -> Address {
    account().base_address(true, Role::Receive, 0).unwrap()
}

fn script() -> StakeCredential {
    StakeCredential::ScriptHash(Hash::new(SCRIPT))
}

/// The script's reward address on preprod: header 0xf0, then its hash.
fn script_reward_account() -> Bytes {
    let mut bytes = vec![0xf0];
    bytes.extend_from_slice(&SCRIPT);
    Bytes::from(bytes)
}

fn tx_hex(
    certificates: Vec<conway::Certificate>,
    withdrawals: Vec<(Bytes, u64)>,
) -> String {
    let body = conway::TransactionBody {
        inputs: Set::from(vec![TransactionInput {
            transaction_id: Hash::new(hex::decode(TX_A).unwrap().try_into().unwrap()),
            index: 1,
        }]),
        outputs: vec![conway::PseudoTransactionOutput::PostAlonzo(
            conway::PostAlonzoTransactionOutput {
                address: Bytes::from(ours().to_vec()),
                value: conway::Value::Coin(2_800_000),
                datum_option: None,
                script_ref: None,
            },
        )],
        fee: 200_000,
        ttl: Some(99_999_999),
        certificates: NonEmptySet::try_from(certificates).ok(),
        withdrawals: NonEmptyKeyValuePairs::try_from(withdrawals).ok(),
        auxiliary_data_hash: None,
        validity_interval_start: None,
        mint: None,
        script_data_hash: None,
        collateral: None,
        required_signers: None,
        network_id: None,
        collateral_return: None,
        total_collateral: None,
        reference_inputs: None,
        voting_procedures: None,
        proposal_procedures: None,
        treasury_value: None,
        donation: None,
    };
    let tx = conway::Tx {
        transaction_body: body,
        transaction_witness_set: conway::WitnessSet {
            vkeywitness: None,
            native_script: None,
            bootstrap_witness: None,
            plutus_v1_script: None,
            plutus_data: None,
            redeemer: None,
            plutus_v2_script: None,
            plutus_v3_script: None,
        },
        success: true,
        auxiliary_data: Nullable::Null,
    };
    hex::encode(tx.encode_fragment().unwrap())
}

/// Found by the extension: the account's 5 ₳ at 0/0.
fn row() -> KoiosRow {
    serde_json::from_value(serde_json::json!({
        "tx_hash": TX_A,
        "tx_index": 1,
        "address": ours().to_bech32().unwrap(),
        "value": "5000000",
        "asset_list": [],
    }))
    .unwrap()
}

fn request(tx: String) -> TxRequest {
    TxRequest {
        network: "preprod".into(),
        tx_cbor: tx,
        keys: (0..3)
            .flat_map(|index| [KeyPath { role: 0, index }, KeyPath { role: 1, index }])
            .collect(),
        inputs: vec![row()],
        // Mesh's default.
        partial_sign: false,
        stake_index: 0,
        stake_deposit: None,
        governance: false,
    }
}

#[test]
fn a_scripts_stake_certificate_needs_no_one_elses_signature() {
    let pool = Hash::new([7; 28]);
    let cases: Vec<(&str, Vec<conway::Certificate>, Vec<(Bytes, u64)>)> = vec![
        // Controls: what the connector already counts as needing no key.
        (
            "control: a script's zero withdrawal",
            vec![],
            vec![(script_reward_account(), 0)],
        ),
        (
            "control: a script DRep's registration",
            vec![conway::Certificate::RegDRepCert(
                script(),
                500_000_000,
                Nullable::Null,
            )],
            vec![],
        ),
        // The finding's shapes.
        (
            "Shelley's registration, cert 0 (the ledger asks no witness at all)",
            vec![conway::Certificate::StakeRegistration(script())],
            vec![],
        ),
        (
            "Conway's registration, cert 7",
            vec![conway::Certificate::Reg(script(), 2_000_000)],
            vec![],
        ),
        (
            "a delegation, cert 2",
            vec![conway::Certificate::StakeDelegation(script(), pool)],
            vec![],
        ),
        (
            "a vote delegation, cert 9",
            vec![conway::Certificate::VoteDeleg(
                script(),
                conway::DRep::Abstain,
            )],
            vec![],
        ),
    ];

    let mut wrong = Vec::new();
    for (name, certificates, withdrawals) in cases {
        let tx = tx_hex(certificates, withdrawals);
        let summary = cip30::inspect_tx(&account(), &request(tx.clone())).unwrap();
        let signed = cip30::sign_tx(&account(), &request(tx));
        let outcome = match &signed {
            Ok(s) => format!("signed by {:?}", s.summary.signs),
            Err(e) => format!("refused: {e}"),
        };
        println!(
            "{name}: others_sign {}, complete {}, {outcome}",
            summary.others_sign, summary.complete
        );
        let right = summary.others_sign == 0
            && summary.complete
            && signed.is_ok_and(|s| s.summary.signs == vec!["0/0".to_string()]);
        if !right {
            wrong.push(name);
        }
    }
    assert!(
        wrong.is_empty(),
        "needs no one else's signature, but counted as needing one: {wrong:#?}"
    );
}
