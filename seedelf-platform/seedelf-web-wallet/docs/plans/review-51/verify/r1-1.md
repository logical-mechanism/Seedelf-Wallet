## Trace: partly, low

The skip holds. `credential_utxos` reads the wallet contract in offset pages, with no order, no limit and no dedupe (seedelf-koios/src/koios.rs:244-268). Suppose a block spends a contract UTxO that sits ahead of a page boundary, between two page requests. The next page's first row then moves onto the page already read, so no request ever returns it. I couldn't refute this, and my test shows it. The test runs the same steps as the CLI's balance (balance.rs:35-39). The wallet holds one 25 ADA UTxO, and the balance comes out as 0 lovelace. In a copy of the tree, a port of koios.ts `paged()` (keyset paging) makes the same test pass.

The case is narrower than the finding says:
- **It needs more than 1,000 UTxOs at the wallet contract on that network.** Preprod passed 1,000 by 2026-10-01 (architecture.md:273). Mainnet held 27 on 2026-10-08 (archive/post-release-roadmap.md:361) and 33 on 2026-10-09 (archive/plans/chunk-26b-data-layer-wallet.md:267). That is one page: page 1 is a single query and offset=1000 comes back empty, so nothing can skip. So the finding's "thousands of rows, several pages" isn't true of mainnet as last recorded.
- **The repeat and reorder half depends on Koios's row order for `credential_utxos`, which I couldn't check offline.** Under an insertion-ordered read, a new UTxO lands after the boundary and nothing repeats: my test reports `repeated []` today.
- **The double-pick refusal is by trace only, not run.**

Nothing is signed wrongly and no money moves. A run gets either a short or doubled figure, or a stopped command, and running the command again is the way out. Who: the user, by an ordinary CLI run that happens to race a block. A stranger can raise the odds by spending junk they placed at the contract every block, but can't choose which run it hits.

**Fix notes:**

**The fix.** In `credential_utxos` (seedelf-koios/src/koios.rs:230-272), port koios.ts `paged()` (extension/src/background/koios.ts:1326-1342):
- send `order=tx_hash.asc,tx_index.asc&limit=1000`;
- start each later page after the last row of the one before, with `or=(tx_hash.gt.<h>,and(tx_hash.eq.<h>,tx_index.gt.<i>))`;
- stop on a short page or on one with nothing new;
- keep each outpoint once, deduped by (tx_hash, tx_index).

I checked in a copy that this exact port makes tests/r51_r1_1.rs pass. The existing CLI harness's `PaginatedUtxos` (seedelf-cli/tests/cli/harness.rs:280-297) keeps working with it: a request with no offset gets the whole fixture, a short page, and the loop stops.

A fixed `order` alone, or a dedupe alone, doesn't fix the skip: a spend ahead of the boundary still shifts an offset.

**Callers.** The one change covers balance, transfer, sweep, remove, fund, util mint, util find, statistics and display::all_seedelfs.

//! Chunk 51, finding r1#1: the CLI reads the wallet contract in `?offset=N`
//! pages (seedelf-koios `credential_utxos`), so a UTxO spent ahead of a page
//! boundary between two page requests moves every later row up by one, and
//! the row at the boundary is never read.
//!
//! The mock stands in for Koios's PostgREST: at most 1,000 rows a request
//! (max-rows), with `offset`, `limit`, `order` and the `or=`/`and=` filters
//! on `tx_hash`, `tx_index` and `block_height`, and with no `order` the rows
//! in the order they were added. A block spends another user's UTxO from the
//! first page between the first and second requests. The wallet's one UTxO,
//! 25 ADA, is the first row of the second page. A read that pages by keyset,
//! as koios.ts `paged()` does, gets it.

use std::collections::BTreeMap;

use seedelf_core::address::wallet_contract;
use seedelf_core::constants::get_config;
use seedelf_core::utxos::{assets_of, collect_all_wallet_utxos, get_credential_utxos};

/// Koios's max-rows.
const MAX_ROWS: usize = 1000;
const PREPROD: bool = true;

/// A distinct 32-byte transaction hash for row `i` (splitmix64), so the order
/// the rows were added in isn't their hash order.
fn hash_of(i: u64) -> String {
    (1..=4u64)
        .map(|k| {
            let mut z = i.wrapping_add(k.wrapping_mul(0x9E37_79B9_7F4A_7C15));
            z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
            z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
            format!("{:016x}", z ^ (z >> 31))
        })
        .collect()
}

/// A wallet-contract UTxO as Koios's `credential_utxos` lists it.
fn row(tx_hash: &str, register: &Register, lovelace: u64, cred: &str, address: &str) -> Value {
    json!({
        "tx_hash": tx_hash,
        "tx_index": 0,
        "address": address,
        "value": lovelace.to_string(),
        "stake_address": null,
        "payment_cred": cred,
        "epoch_no": 290,
        "block_height": 3_000_000,
        "block_time": 1_700_000_000,
        "datum_hash": null,
        "inline_datum": {"bytes": hex::encode(register.to_vec().expect("register cbor")), "value": null},
        "reference_script": null,
        "asset_list": [],
        "is_spent": false
    })
}

/// A PostgREST condition on a row.
enum Cond {
    Cmp(String, String, String),
    Any(Vec<Cond>),
    All(Vec<Cond>),
}

fn cmp_of(col: &str, op_value: &str) -> Result<Cond, String> {
    let (op, value) = op_value
        .split_once('.')
        .ok_or_else(|| format!("unreadable filter {col}={op_value}"))?;
    if !["tx_hash", "tx_index", "block_height"].contains(&col) {
        return Err(format!("the mock doesn't filter on {col}"));
    }
    if !["eq", "neq", "gt", "gte", "lt", "lte"].contains(&op) {
        return Err(format!("the mock doesn't know the operator {op}"));
    }
    Ok(Cond::Cmp(col.into(), op.into(), value.into()))
}

/// `(a,b,…)` of a logic tree, each `col.op.value`, `or(…)` or `and(…)`.
fn tree_of(all: bool, list: &str) -> Result<Cond, String> {
    let inner = list
        .strip_prefix('(')
        .and_then(|s| s.strip_suffix(')'))
        .ok_or_else(|| format!("unreadable logic tree {list}"))?;
    let (mut items, mut depth, mut start) = (Vec::new(), 0, 0);
    for (i, c) in inner.char_indices() {
        match c {
            '(' => depth += 1,
            ')' => depth -= 1,
            ',' if depth == 0 => {
                items.push(&inner[start..i]);
                start = i + 1;
            }
            _ => {}
        }
    }
    items.push(&inner[start..]);
    let conds = items
        .into_iter()
        .map(|item| {
            if let Some(rest) = item.strip_prefix("or") {
                tree_of(false, rest)
            } else if let Some(rest) = item.strip_prefix("and") {
                tree_of(true, rest)
            } else {
                let (col, op_value) = item
                    .split_once('.')
                    .ok_or_else(|| format!("unreadable condition {item}"))?;
                cmp_of(col, op_value)
            }
        })
        .collect::<Result<Vec<_>, _>>()?;
    Ok(if all {
        Cond::All(conds)
    } else {
        Cond::Any(conds)
    })
}

fn order_of(a: &Value, b: &Value, col: &str) -> std::cmp::Ordering {
    match col {
        "tx_hash" => a[col].as_str().cmp(&b[col].as_str()),
        _ => a[col].as_u64().cmp(&b[col].as_u64()),
    }
}

fn holds(cond: &Cond, row: &Value) -> Result<bool, String> {
    Ok(match cond {
        Cond::Any(conds) => conds
            .iter()
            .map(|c| holds(c, row))
            .collect::<Result<Vec<_>, _>>()?
            .contains(&true),
        Cond::All(conds) => !conds
            .iter()
            .map(|c| holds(c, row))
            .collect::<Result<Vec<_>, _>>()?
            .contains(&false),
        Cond::Cmp(col, op, value) => {
            let ord = if col == "tx_hash" {
                row[col.as_str()]
                    .as_str()
                    .unwrap_or_default()
                    .cmp(value.as_str())
            } else {
                let n: u64 = value
                    .parse()
                    .map_err(|_| format!("{col} isn't compared with a number: {value}"))?;
                row[col.as_str()].as_u64().unwrap_or_default().cmp(&n)
            };
            match op.as_str() {
                "eq" => ord.is_eq(),
                "neq" => ord.is_ne(),
                "gt" => ord.is_gt(),
                "gte" => ord.is_ge(),
                "lt" => ord.is_lt(),
                _ => ord.is_le(),
            }
        }
    })
}

/// What PostgREST answers for `request` over `rows`, in the order they were added.
fn page(rows: &[&Value], request: &Request) -> Result<Vec<Value>, String> {
    let (mut offset, mut limit) = (0usize, MAX_ROWS);
    let mut order: Vec<(String, bool)> = Vec::new();
    let mut conds: Vec<Cond> = Vec::new();
    for (key, value) in request.url.query_pairs() {
        match key.as_ref() {
            "offset" => offset = value.parse().map_err(|_| format!("bad offset {value}"))?,
            "limit" => limit = limit.min(value.parse().map_err(|_| format!("bad limit {value}"))?),
            "select" => {}
            "order" => {
                order = value
                    .split(',')
                    .map(|term| {
                        let mut parts = term.split('.');
                        let col = parts.next().unwrap_or_default().to_string();
                        (col, parts.next() == Some("desc"))
                    })
                    .collect()
            }
            "or" => conds.push(tree_of(false, &value)?),
            "and" => conds.push(tree_of(true, &value)?),
            col => conds.push(cmp_of(col, &value)?),
        }
    }
    let mut kept: Vec<&Value> = Vec::new();
    for row in rows {
        if conds
            .iter()
            .map(|c| holds(c, row))
            .collect::<Result<Vec<_>, _>>()?
            .iter()
            .all(|h| *h)
        {
            kept.push(row);
        }
    }
    kept.sort_by(|a, b| {
        order
            .iter()
            .fold(std::cmp::Ordering::Equal, |acc, (col, desc)| {
                acc.then_with(|| {
                    let ord = order_of(a, b, col);
                    if *desc { ord.reverse() } else { ord }
                })
            })
    });
    Ok(kept.into_iter().skip(offset).take(limit).cloned().collect())
}

/// Koios over the contract: `spent` leaves the set once the first request is answered.
struct Koios {
    cred: String,
    rows: Vec<Value>,
    spent: String,
    answered: std::sync::atomic::AtomicUsize,
}

impl Respond for Koios {
    fn respond(&self, request: &Request) -> ResponseTemplate {
        let body: Value = serde_json::from_slice(&request.body).unwrap_or(Value::Null);
        if body["_payment_credentials"] != json!([self.cred]) {
            return ResponseTemplate::new(400).set_body_string("not the contract's credential");
        }
        let after_block = self
            .answered
            .fetch_add(1, std::sync::atomic::Ordering::SeqCst)
            > 0;
        let live: Vec<&Value> = self
            .rows
            .iter()
            .filter(|r| !after_block || r["tx_hash"] != self.spent.as_str())
            .collect();
        match page(&live, request) {
            Ok(rows) => ResponseTemplate::new(200).set_body_json(rows),
            Err(why) => ResponseTemplate::new(400).set_body_string(why),
        }
    }
}
