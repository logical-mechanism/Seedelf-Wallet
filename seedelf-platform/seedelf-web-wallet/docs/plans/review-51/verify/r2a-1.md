## Trace: confirmed, low

The finding holds. `build::is_payable_address` (seedelf-core/src/build.rs:3280-3284) refuses any Shelley address with a script in either part. It does this through `is_not_a_script` and Pallas's `Address::has_script`, which is `payment().is_script() || delegation().is_script()`. So a key-payment address whose stake part is a script (CIP-19 type 2, `addr1y…` / `addr_test1y…`) is refused. That covers public Send, Make public (with an amount, Max and sweep_most), contacts and ADA Handles. The screen says "That's a script's address … could be locked there for good", which is false: the ledger takes the output, no datum is involved, and only the payment key spends it. I found no guard, caller or type that avoids the refusal.

The test I added fails on TREE for exactly this reason. A plain key/key control in the same fixture passes. The test passes once the predicate checks only the payment part, which I ran in a copy.

One narrowing, which doesn't change the verdict: the web wallet's Remove never takes a typed address. Its destination is the account's own 0/0 or the private balance (withdraw.ts:175-180). So "Remove's ADA to an address" applies only to the CLI's `remove --address`.

Severity is low. Only the user reaches it, through an ordinary payment to a rare address shape. No money is lost or locked; the payment is just refused, with wrong words. There is a way out: the phrase restores in any CIP-1852 wallet, which can pay that address. From the private side, the user would first have to Make public to their own address, which links the two. That is a small cost in an edge case, and no stuck state.

The finder's grade (low) and needs_owner (yes) both stand. Chunk 10's work item and mint_test pin the current rule, so the fix changes which addresses Send and Make public accept.

//! Chunk 51, finding r2a#1 (also r2b#1, w1b#1's first case).
//!
//! A key address whose stake part is a script (CIP-19 header type 2:
//! `addr1y…`, `addr_test1y…`) is an ordinary payee: the ledger takes an
//! output there with no datum, and only its payment key can spend it, so
//! nothing paid to it can be locked. `build::is_payable_address` refuses it
//! today, because `is_not_a_script` (address.rs:63) uses Pallas's
//! `has_script`, which counts the stake part too. Public Send, Make public,
//! contacts and handles all go through that predicate.
//!
//! The right behaviour, asserted here: it's payable on its own network, and
//! a public Send of 3 ₳ pays it exactly, with no datum.

use pallas_addresses::{
    Address, Network, ScriptHash, ShelleyAddress, ShelleyDelegationPart, ShelleyPaymentPart,
};
use pallas_traverse::MultiEraTx;
use seedelf_core::build::{self, AccountAmount};
use seedelf_core::staking::Staking;
use seedelf_crypto::cardano::{CardanoAccount, Role};
use seedelf_koios::koios::{ProtocolParameters, UtxoResponse};

const PHRASE: &str =
    "abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about";

/// Someone else's payment key (account 1 of the phrase), staked by a script
/// (a multisig's native stake script, say), read back from bech32 as a user
/// pastes it.
fn key_staked_by_a_script(network: Network) -> Address {
    let payee = CardanoAccount::from_phrase(PHRASE, 1).unwrap();
    let text = Address::from(ShelleyAddress::new(
        network,
        ShelleyPaymentPart::Key(payee.key_hash(Role::Receive, 0).unwrap()),
        ShelleyDelegationPart::Script(ScriptHash::new([9; 28])),
    ))
    .to_bech32()
    .unwrap();
    Address::from_bech32(&text).unwrap()
}

#[test]
fn a_key_address_whose_stake_part_is_a_script_is_paid() {
    let preprod = key_staked_by_a_script(Network::Testnet);
    let mainnet = key_staked_by_a_script(Network::Mainnet);
    assert!(preprod.to_bech32().unwrap().starts_with("addr_test1y"));
    assert!(mainnet.to_bech32().unwrap().starts_with("addr1y"));

    // Public Send (`account_send`): 3 ₳ from a 30 ₳ UTxO at the account's 0/0.
    let rows: serde_json::Value =
        serde_json::from_str(include_str!("fixtures/epoch_params.json")).unwrap();
    let params = ProtocolParameters::from_koios(&rows[0]).unwrap();
    let account = CardanoAccount::from_phrase(PHRASE, 0).unwrap();
    let change = account.base_address(true, Role::Receive, 0).unwrap();
    let available = vec![UtxoResponse {
        tx_hash: hex::encode([1u8; 32]),
        tx_index: 0,
        address: change.to_bech32().unwrap(),
        value: "30000000".to_string(),
        payment_cred: hex::encode(account.key_hash(Role::Receive, 0).unwrap()),
        asset_list: Some(Vec::new()),
        ..Default::default()
    }];
    let send = |to: &Address| {
        build::account_send(
            &params,
            &available,
            AccountAmount::Lovelace(3_000_000),
            &[],
            to,
            true,
            &change,
            &Staking::none(),
            None,
        )
    };

    // The control: the same payee's key, staked by a key, is paid.
    let plain = CardanoAccount::from_phrase(PHRASE, 1)
        .unwrap()
        .base_address(true, Role::Receive, 0)
        .unwrap();
    assert!(build::is_payable_address(&plain, true));
    assert!(send(&plain).is_ok(), "the fixture pays a plain key address");

    // Only the stake part differs.
    let payable = (
        build::is_payable_address(&preprod, true),
        build::is_payable_address(&mainnet, false),
    );
    let sent = send(&preprod);
    assert!(
        payable == (true, true) && sent.is_ok(),
        "is_payable_address (preprod, mainnet): {payable:?}; public Send of 3 ₳: {:?}",
        sent.as_ref().err().map(|e| e.to_string())
    );

    let built = sent.unwrap();
    let tx = MultiEraTx::decode(&built.tx.tx_bytes.0).unwrap();
    let paid: Vec<_> = tx
        .outputs()
        .into_iter()
        .filter(|o| o.address().unwrap() == preprod)
        .collect();
    assert_eq!(paid.len(), 1, "one output pays it");
    assert_eq!(paid[0].value().coin(), 3_000_000);
    assert!(paid[0].datum().is_none(), "a key address needs no datum");
}
