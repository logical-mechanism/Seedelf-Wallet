## Trace: confirmed, low

The finding holds as described, and I found no guard it missed. The sign window's register reader, cip30.rs register_datum, accepts constructor 0 only as tag 121. Pallas keeps a site's tag-102 spelling through both decode and re-encode. So a payable register written 102([0, [g, u]]), with definite or indefinite fields, gets the label "none". The window then shows "It pays Seedelf Wallet's contract without a register: whatever goes there, anyone can take." in place of "It pays a Seedelf…". signingTies gets seedelf=false, so with nothing else tied the privacy line adds "Your private balance isn't in it." A session's window says "Your public account and your private balance aren't in it." Transaction details read the bytes through the same function and show "with a datum", not "under a register".

Both spellings are valid. The node's own decoder (cardano-cli 11.0.0.0, run offline) reads them as Constr 0 [g, u] at the contract's address. The deployed wallet.ak checks `if register is Register` on that Data, so only the register's key can spend the output. The wallet's own readers (koios register_of_datum, chain.ts registerOf) take this spelling. So a payment to the user's own register lands in their private balance and can be spent there.

Nothing upstream stops it. check_nesting looks at depth only. The worker's ties match keys and never read a register. No existing test uses tag 102 at cip30.

Grade, low (I agree with the finder):
- **Who:** a site, which writes the bytes. A stranger reaches only the Transaction-details half: an incoming payment in this spelling reads "with a datum", which is cosmetic.
- **Cost:** no money moves other than shown. The address, amount and Pays row ("Seedelf Wallet's contract, with data") are right. The money warning errs on the cautious side.
- **The false privacy line:** it matters only when the register is the user's own. The site has to know that register, write this rare spelling, and get the user to sign through a red "anyone can take" warning. That is not a link made by default.
- **Way out:** decline. Nothing is lost.

//! Chunk 51, finding x3#1: the connector window reads a Seedelf payment's
//! register with cip30's `register_datum`, which takes constructor 0 only as
//! tag 121. Constructor 0's general form, `102([0, fields])`, is the same
//! Plutus data: the node decodes it as `Constr 0 [g, u]`, the deployed

fn account() -> CardanoAccount {

fn keys() -> Vec<KeyPath> {

fn ours(role: Role, index: u32) -> Address {

fn row(tx: &str, index: u64, address: &Address, lovelace: u64) -> KoiosRow {
    serde_json::from_value(serde_json::json!({
        "tx_hash": tx,
        "tx_index": index,
        "address": address.to_bech32().unwrap(),
        "value": lovelace.to_string(),
        "asset_list": [],
    }))
    .unwrap()
}

fn input(tx: &str, index: u64) -> TransactionInput {
    TransactionInput {
        transaction_id: Hash::new(hex::decode(tx).unwrap().try_into().unwrap()),
        index,
    }
}

fn out(address: &Address, lovelace: u64, datum: &str) -> conway::TransactionOutput {
    conway::PseudoTransactionOutput::PostAlonzo(conway::PostAlonzoTransactionOutput {
        address: Bytes::from(address.to_vec()),
        value: conway::Value::Coin(lovelace),
        datum_option: Some(conway::PseudoDatumOption::Data(CborWrap(
            PlutusData::decode_fragment(&hex::decode(datum).unwrap()).unwrap(),
        ))),
        script_ref: None,
    })
}

fn plain(address: &Address, lovelace: u64) -> conway::TransactionOutput {
    conway::PseudoTransactionOutput::PostAlonzo(conway::PostAlonzoTransactionOutput {
        address: Bytes::from(address.to_vec()),
        value: conway::Value::Coin(lovelace),
        datum_option: None,
        script_ref: None,
    })
}

#[test]
fn a_seedelf_payment_in_constructor_0s_general_form_reads_as_under_a_register() {
    // The register's two fields as written: 5830 <g> 5830 <u>.
    let fields = &REGISTER_DATUM[6..REGISTER_DATUM.len() - 2];
    // 102([0, [_ g, u]]): the general form, with the fields indefinite.
    let general_indef = format!("d86682009f{fields}ff");
    // 102([0, [g, u]]): the general form, with the fields definite.
    let general_def = format!("d866820082{fields}");

    // The same Plutus data as the canonical spelling: Pallas compares a
    // constructor by its index and fields, as the ledger reads it.
    let canonical = PlutusData::decode_fragment(&hex::decode(REGISTER_DATUM).unwrap()).unwrap();
    for spelling in [&general_indef, &general_def] {
        let data = PlutusData::decode_fragment(&hex::decode(spelling).unwrap()).unwrap();
        assert_eq!(data, canonical, "{spelling} is Constr 0 [g, u]");
        // Pallas writes it back as written, tag 102 and all: what cip30's
        // output_parts hands register_datum.
        assert_eq!(hex::encode(data.encode_fragment().unwrap()), *spelling);
    }

    // The wallet's own reader, which every Rust spend path and check_spendable
    // use, reads both spellings as the very register the canonical one holds.
    // Holds today.
    let register = seedelf_koios::koios::register_of_datum(&hex::decode(REGISTER_DATUM).unwrap())
        .expect("the canonical register reads");
    assert!(seedelf_core::build::is_payable(&register));
    for spelling in [&general_indef, &general_def] {
        assert_eq!(
            seedelf_koios::koios::register_of_datum(&hex::decode(spelling).unwrap()),
            Some(register.clone()),
            "the wallet's scan reads {spelling} as the register"
        );
    }

    // A site's transaction: the account's 10 ₳ pays 2 ₳ into Seedelf Wallet's
    // contract under each spelling of the same payable register, and its change.
    let contract = seedelf_core::address::wallet_contract(
        true,
        seedelf_core::constants::get_config(1, true)
            .unwrap()
            .contract
            .wallet_contract_hash,
    );
    let rows = vec![row(TX_A, 0, &ours(Role::Receive, 0), 10_000_000)];
    let tx = tx_hex(
        vec![input(TX_A, 0)],
        vec![
            out(&contract, 2_000_000, REGISTER_DATUM),
            out(&contract, 2_000_000, &general_indef),
            out(&contract, 2_000_000, &general_def),
            plain(&ours(Role::Change, 0), 3_800_000),
        ],
    );
    let request = TxRequest {
        network: "preprod".into(),
        tx_cbor: tx.clone(),
        keys: keys(),
        inputs: rows,
        partial_sign: false,
        stake_index: 0,
        stake_deposit: None,
        governance: false,
    };
    let summary = cip30::inspect_tx(&account(), &request).unwrap();
    assert_eq!(summary.paid.len(), 3, "the change is the account's own");
    // The canonical spelling reads as under a register. Holds today.
    assert_eq!(summary.paid[0].seedelf.as_deref(), Some("register"));

    let detail = decode_tx("preprod", &tx).unwrap();
    assert!(detail.outputs[..3].iter().all(|o| o.address.seedelf));
    let shown = |i: usize| {
        detail.outputs[i]
            .register
            .as_ref()
            .map(|r| (r.generator.clone(), r.public_value.clone(), r.payable))
    };
    let expected = Some((register.generator.clone(), register.public_value.clone(), true));
    // Transaction details shows the canonical one under its register. Holds today.
    assert_eq!(shown(0), expected);

    // The same register in the general form must read the same: "register"
    // shows "It pays a Seedelf…", "none" warns "…without a register: whatever
    // goes there, anyone can take." and, with nothing else tied, the privacy
    // line adds "Your private balance isn't in it."
    let mut wrong = Vec::new();
    for (i, spelling) in [(1, "102([0, [_ g, u]])"), (2, "102([0, [g, u]])")] {
        if summary.paid[i].seedelf.as_deref() != Some("register") {
            wrong.push(format!(
                "sign window: output {i}, {spelling}, is labelled {:?}, not \"register\"",
                summary.paid[i].seedelf
            ));
        }
        if shown(i) != expected {
            wrong.push(format!(
                "Transaction details: output {i}, {spelling}, shows register {:?}",
                shown(i)
            ));
        }
    }
    assert!(wrong.is_empty(), "{wrong:#?}");
}
