While this moves to Z3 5.3.1: the README's *Installation and building* still says "Install z3 version 4.15.2." With the beta-based Blaster (from `88588c5`, "set min z3 version to 5.3.1"), every proof that reaches the solver fails on 4.15.2 with `invalid tactic, unknown tactic recfun-finder` (the simplifier arrived in Z3 5.3.0), while goals the optimizer closes still pass, so it looks half-working. Lean-blaster's own README says both (4.15.2 in the badge and install section, 5.3.1 under Prerequisites). Worth updating here with the dependency.

Also worth knowing: both this PR's Blaster pin (`8816f72`) and the current one (`bc03bb4`) have a beta-branch regression that Lean-blaster `main` doesn't, input-output-hk/Lean-blaster#454. A datatype gets declared with the parameter names of an earlier alpha-equivalent type, so any goal with both `Except` and `Prod` fails to translate. Here that's every goal reaching a BLS12-381 builtin over a symbolic input (they return `Except String _`, after the CEK model's `Data × Data`). The fix is one line, input-output-hk/Lean-blaster#455; worth picking up in the pin once it's in.
