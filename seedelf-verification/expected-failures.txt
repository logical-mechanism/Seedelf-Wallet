# records reads EXPECTED, which fails no run, where it would read FAILED. Just as recorded: each
# theorem `fails:` names fails with an error that begins as `with:` does; nothing else in the module
# fails, is Undetermined, a sorry or a ❌; its other theorems print every ✅ their source has; and
# no other module fails in its build. Anything else reads FAILED, saying what differs. A failed
# build leaves no trace, so check.sh reads this from the build's console, and tally.py still lists
# the module as not ok (no trace).
#
# One entry a module, by its name, with the theorems that fail (as its source names them), the
# error they fail with, why that's by design, and when it was seen. Each entry is a claim about the
# proofs, so each is the owner's to approve, in the PR that adds it. An entry with no why or no
# when counts for nothing.
